# 客户专项年中总结报告模板需求

## 输出目标

基于 `template-PPT.pptx` 的视觉风格，制作 3 页可填充的模块模板页。每页保留数据占位符，后续由用户填充真实内容和数据。

## 模块 1：系统搭建

- 核心主题：系统搭建进展
- 预期内容：建设里程碑、关键模块、当前状态、下一步计划
- 图表占位：项目进度 / 里程碑时间轴

## 模块 2：风险品处置

- 核心主题：预警触发到处置闭环
- 预期指标：触发预警数量、风险产品数、产品处置数
- 图表占位：三项指标漏斗 / 闭环转化图 / KPI 卡片

## 模块 3：制程提升

- 核心主题：制程优化和专项改善进展
- 预期指标：CPK 优化数、流程优化项、专项进展
- 图表占位：优化前后对比 / 专项进展矩阵 / 趋势图

## 写作约束

- 不填充未经用户提供的真实数据。
- 所有数字使用占位符，如 `XX`、`XX%`、`YYYY-MM`。
- 页面应当方便后续直接替换标题、指标、图表数据和备注。
