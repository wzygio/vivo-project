# 客户专项年中总结建议表格

## 输出范围

新建一份独立 PPT，仅包含建议填充的数据表模板，不写回原始 PPT。

## 表格清单

1. 表格索引与图表映射
   - 用途：说明每张表支撑哪些汇报页和图表。

2. 系统搭建里程碑表
   - 用途：支撑“系统搭建进展总览”的时间轴。
   - 关键字段：阶段、关键任务、计划完成、实际进度、完成率、责任人、风险/阻塞、下一步。

3. 系统模块建设清单
   - 用途：支撑“关键模块状态”卡片。
   - 关键字段：模块名称、建设内容、当前状态、接口/规则数、上线范围、备注。

4. 风险品处置闭环明细表
   - 用途：支撑截图中的“计划补充：已关闭 / 持续跟进 / 升级专项 / 责任部门 / 截止日期 / 闭环说明”。
   - 关键字段：产品/型号、预警来源、预警数、风险等级、处置状态、责任部门、截止日期、闭环说明。

5. 风险品处置统计汇总表
   - 用途：支撑风险处置 KPI 卡片和漏斗图。
   - 关键字段：触发预警数量、风险产品数、已关闭、持续跟进、升级专项、产品处置数、闭环率。

6. 制程提升改善项目表
   - 用途：支撑 CPK 优化、流程优化和专项进展页。
   - 关键字段：专项/工序、问题点、优化动作、CPK 优化前后、提升幅度、进度、固化输出。
