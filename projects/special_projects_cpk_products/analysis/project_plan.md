# 专项项目与 CPK 图表输出计划

## 图一项次整理为专项项目

原图左侧归属：移班专项 / PT 专项遗留。

1. 报表上线与数据确认专项
   - 来源项次：电流电压、光学报表预计 6/22 进行上线测试，待确认最终提交数据。
   - 建议输出：上线测试结论、最终提交数据清单、异常项闭环记录。

2. 彩斑/点类不良 AVI 检验与复判标准专项
   - 来源项次：针对彩斑、点类不良提供 AVI 设备检验原理及算法，及人员复判的标准。
   - 建议输出：设备检验原理说明、算法逻辑、人员复判 SOP。

3. Z571 放量与彩斑拦截优化专项
   - 来源项次：Z571 项目放量策划，针对上一代彩斑的优化拦截措施。
   - 建议输出：放量计划、上一代问题复盘、拦截策略与验证结果。

4. CVD Mask 来料刮伤监控与处置专项
   - 来源项次：提供 CVD Mask 来料针对刮伤监控 rule 和处理方式。
   - 建议输出：监控规则、判定标准、处置流程与责任分工。

5. Particle 改善措施与效果预估专项
   - 来源项次：罗列目前针对 particle 改善的具体措施及对策预估效果，设备优化可单独体现。
   - 建议输出：改善措施清单、效果预估、设备优化拆分项、验证计划。
