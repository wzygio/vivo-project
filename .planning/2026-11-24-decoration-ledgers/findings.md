# 范围与发现

16 个页面入口。日矩阵另有指标×产品公共显示工作簿。HTTP 支持四域 Sheet OOS/OOC、SPC CPK/CPM、Yield Lot 和 Q-Time。通知复用 HTTP；巡检额外生产 AOI 趋势与辅助域预警。

## 页面审计

| 页面 | 独立预警 / 本次处理 |
|---|---|
| SPC、CTQ、AOI_TT、AOI_RS | 共享 OOS/OOC 维护，SPC 增 CPK/CPM，AOI 增趋势 |
| 入库不良率分析看板 | Lot 和趋势分别维护 |
| Q-Time 监控 | 站点超规；Chamber 查询没有独立预警 |
| IJP 溢流监控 | AA 区和孔区分别维护 |
| 关键备件、IQC 蒸镀材料、寿命测试 | 各自发布来源维护 |
| 自动预警看板 | 维护独立的指标 × 产品总显示决定 |
| 入库 BySheet、ByLot、密集点、专项资料、历史预警看板 | 明细、资料或跨域汇总，无独立预警事项 |

## 交叉审查

真实浏览器发现连续修改矩阵决定时控件状态错位，保存后重跑修复。专项审查识别寿命排序编号不稳定、人工上传刷新事实时间、陈旧的全量下载表互相覆盖；已分别纳入对应票据验证。16 个入口共十个业务报表、一个矩阵管理入口、五个只读或汇总页面。
