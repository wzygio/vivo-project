# 入库良率修饰逻辑简化：删除 Codebaseline/EMA/截断/人工覆盖链路，改为"入库良率修饰表"指定良损驱动

Status: `complete`

Source: `docs/dev_docs/dev_spec/yield_domain/feat-mwd_processor-opt.md`

## Current context

- Code 级趋势（`src/yield_domain/core/mwd_trend/mwd_trend_processor.py:167`）链路为：原始日度统计 → `code_baseline.py`（`resources/codebaseline.xlsx` 基线锚定）→ `ema.py`（月内有界 EMA + **正弦**噪声）→ `trend_regulator.py`（警戒线压制）→ `allocation.reconcile_code_daily_counts`（月度整数校准）→ `pipeline.run_manual_period_pipeline` + `manual_overrides.py`（消费 `resources/趋势图人工修正.xlsx` 的月/周/日覆盖，由 `excel_service.inject_excel_overrides_to_config:230` 注入 `config.processing`）。
- Group 级趋势（同文件 `:98`）不独立计算，由 Code 日度按 Group 汇总后走同一人工覆盖管线。
- Mapping 图（`core/mapping/mapping_processor.py:22`）：以批次为粒度、只取最新 5 个批次；不良数 = 每 `(batch_no, defect_desc)` 行数；现有影响因子为 `defect_modifier.apply_defect_multipliers`（YAML 全局倍率，`yield_service.py:159`）与 Rate-Based 级联衰减（`mapping_processor.py:137-189`）。级联衰减为红线，禁止静态重构（`.roorules:48`）。
- `resources/入库良率修饰表.xlsx`（企业加密）已存在 10 个 Sheet（M626/M678/Z571/M673/Z517 × Group级/Code级），列固定为 `不良类型 | 周期类型 | 时间标签 | 当月良损 | 指定良损 | 缩放倍数`；`当月良损` 已填 2026-06/07/08，`指定良损`/`缩放倍数` 全空。全仓无任何代码读写该表（检索仅命中需求文档）。
- 加密 Excel 读取（`_read_encrypted_xlsx_via_com`）与写回（`excel_tools.replace_workbook_sheet`，企业加密时整体重写明文，与 `codebaseline.xlsx` 既有行为一致）基础设施齐备。
- 报表将交接业务人员维护，现链路只有开发人员能理解（需求背景）。

## Desired outcome

- 趋势图修饰全部来自"入库良率修饰表"：业务人员只需填写 `指定良损`（月度），系统按确定性算法生成日度数据并聚合周/月；`指定良损` 为空时回落原始数据（缩放倍数 1.0）。
- 每次运行只更新修饰表当月行的 `当月良损`；检测到 `指定良损` 改动时重算并回写 `缩放倍数`（两位小数，`= 指定良损 / 当月良损`）。
- 日度生成：同输入多次运行结果完全一致（稳定哈希而非随机数）；无周期性震荡；跨月过渡平滑无阶梯；月度合计精确等于 `round(指定良损 × 当月投入)`。
- Mapping 不良数同步乘以"批次所属月份的缩放倍数"（Code 级 Sheet），使月周日趋势与 Mapping 不良数水准一致；级联衰减逻辑不变。
- Codebaseline/EMA/趋势调节/月度校准/人工覆盖链路及其测试全部删除；`趋势图人工修正.xlsx` 文件保留但不再被消费。

## Acceptance criteria

- [ ] 修饰表管理器：读取 `<prod>_Group级`/`<prod>_Code级`（加密回退 COM）；计算当月原始良损并仅回写当月行；`指定良损` 签名变化时重算并回写 `缩放倍数`（两位小数，除零/缺失记 1.0）；文件缺失/Sheet 缺失/被占用时按空表语义出图且仅记日志。
- [ ] 上月回退：某不良类型当月无 `指定良损` 时使用最近一个有 `指定良损` 的上月值；从无指定则用 `当月良损`。
- [ ] 日度生成器：同输入两次运行结果逐行一致；月度合计 == `round(rate × 当月投入)`；单日不良数 ≤ 当日投入；跨月首尾日基线率连续（无阶梯）；日度序列无固定周期震荡。
- [ ] Group 趋势由 Code 日度按 Group 汇总（D1 评审调整），Group 级 Sheet 照常回写当月良损/缩放倍数但不驱动生成；周/月由最终日度直接聚合，无任何人工覆盖步骤。
- [ ] Mapping：`prepare_mapping_data` 新增 `monthly_factors` 参数，在级联衰减之前按 `(defect_desc, 批次月份)` 确定性抽样/复制（复制行 `_SIM_M` 后缀防碰撞）；缺省因子 1.0 时结果与现状一致；级联衰减代码未改动。
- [ ] `get_mapping_data` 传入 Code 级缩放因子后，同一 Code 的月趋势不良数与 Mapping 同月不良数在月度口径一致（约等于 `指定良损 × 投入`）。
- [ ] 删除清单落地：`code_baseline.py`、`ema.py`、`trend_regulator.py`、`manual_overrides.py`、`pipeline.py`、模块级兼容入口、`inject_excel_overrides_to_config` 趋势覆盖部分、`defect_modifier.py` 死代码（`_build_weight_maps`/`_get_dispersion_target`）、相关旧测试。
- [ ] 缓存 key 包含修饰表签名：业务改表后页面"刷新缓存"即生效；缓存命中不重读/重写工作簿。
- [ ] CLI `tools/update_yield_modifier_table.py --product <code>` 可手动触发当月良损与缩放倍数写回。
- [ ] 定向单元测试全部通过；全量 pytest 不引入新失败（既有失败基线除外）。
- [ ] 入库不良率分析看板 E2E 通过：指定良损 → Code 月趋势 == 指定水准且 Mapping 一致；清空指定 → 回落原始数据。

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement  
**Summary:** 删除入库良率的 "Codebaseline→EMA→趋势调节→月度校准→人工覆盖" 修饰链路，改为由 `resources/入库良率修饰表.xlsx` 的"指定良损"驱动：按月目标良损确定性生成日度数据并聚合周/月，同时把月度缩放倍数接入 Mapping 不良数（级联衰减红线不动）。

**Current behavior:**

- Code 级趋势：`prepare_code_raw_data` → `pad_daily_data_to_end` → `ema.calculate_code_ema_noise`（codebaseline.xlsx 锚定 + 正弦噪声）→ `TrendRegulator` → `reconcile_code_daily_counts` → `run_manual_period_pipeline`（消费 `config.processing` 中六类覆盖，来自 `趋势图人工修正.xlsx`）→ `format_code_results`。
- Group 级趋势：由 Code 日度汇总（`_build_group_daily_from_code_data`）后走同一覆盖管线。
- Mapping：`apply_defect_multipliers`（YAML 全局）→ 位置修饰 → 级联衰减；只取最新 5 个批次，批次日期解析自 `batch_no`。
- `入库良率修饰表.xlsx` 已存在但无代码读写；`指定良损`/`缩放倍数` 列全空。

**Required behavior:**

- 新模块 `core/mwd_trend/modifier_table.py`：读修饰表（COM 回退）、算当月原始良损、上月回退解析、缩放倍数（两位小数）、`指定良损` 签名检测、当月行与缩放倍数写回（`replace_workbook_sheet`，失败仅记日志）。
- 新模块 `core/mwd_trend/daily_generator.py`：月中锚点线性插值基线（跨月平滑）+ blake2b 哈希白噪声（无周期、完全确定）+ 月内最大余数整数分配（月合计精确等于目标，单日 ≤ 当日投入）。
- facade 重写：Code 级由 Code Sheet 指定良损驱动生成；Group 级保留
  `mwd_code_data` 入参，由 Code 日度按 Group 汇总（D1 评审调整）；
  周/月直接 `safe_trend_aggregator` 聚合；删除 EMA/调节/校准/覆盖全部中间步骤
  与相关参数（`ema_span`/`scaling_factor`/`warning_lines`）。
- Mapping：`prepare_mapping_data` 新增 `monthly_factors` 可选参数，在级联衰减前按 `(defect_desc, 批次月份)` 确定性缩放（下采样 `random_state=42`；上采样复制 + `_SIM_M` 后缀）；级联代码一行不动。
- Service 接线：缓存 key 含修饰表签名；`get_mapping_data` 传 Code 级因子；删除 `inject_excel_overrides_to_config` 趋势覆盖部分（保留 mapping 配置注入）；CLI `tools/update_yield_modifier_table.py`。
- 安全默认：`指定良损` 全空 → 全部回落原始数据，因子 1.0。

**Key interfaces:**

- `read_modifier_table(path, product_code) -> dict[str, DataFrame]`；`resolve_monthly_targets(table_df, months) -> dict[(不良类型, 月份), rate]`；`compute_scale_factors(table_df) -> dict[(不良类型, 月份), float]`；`sync_modifier_table(path, product_code, panel_details_df)`。
