## Current context

- SPC 页面按当前产品加载上一个自然月首日至当天的点位明细、规格、Sheet 特征和周期能力结果，并按厂别、站点、参数名称筛选。
- 第二幅图当前直接使用检测量测记录的 `unit_id`，并截取连字符前缀作为腔室标签；它没有使用规格定义的主制程站点，也没有查询主制程过站履历。
- 参数规格表以“产品型号、检测站点、参数名称”唯一定位规格，同时提供 `main_step_id` 和 `main_eqp_type`。只读数据库核验显示该三元组共 1352 行且全部唯一。
- 北极星既有逻辑按厂别和 `main_eqp_type` 路由到 ARRAY Sheet、OLED/TP Glass 的整机或子单元 OUT 履历；OLED 腔室还需使用工序映射表归一化 CVD 工序。
- 现有 SPC 快照只含检测量测 `unit_id`。新追溯字段必须进入快照结构版本检查，避免旧快照被误认为完整数据。

## Desired outcome

- 第二幅图保持现有点位分布、颜色、排序和规格线样式，但分组设备/腔室来自每条量测对应的主制程站点 OUT 履历。
- 主制程路由由规格的 `main_step_id` 与 `main_eqp_type` 决定；缺失值分别回退当前检测站点和 `EQP`。
- 每条量测选择其量测时刻之前、追溯窗口内最近的匹配 OUT 履历，避免同一物料多次过站造成点位多对多放大。
- 正式 CHAMBER 履历缺失时显示可诊断的未知标签；正式 EQP 履历缺失时按既有北极星语义回退量测设备 `unit_id`。
- 页面筛选、第一/第三幅图、CPM/CPK 计算、人工修饰、缓存刷新与预警行为保持不变。

## Acceptance criteria

- [x] 规格数据契约包含 `main_step_id`、`main_eqp_type`，并继续以产品型号、检测站点、参数名称唯一匹配，不放大量测行。
- [x] ARRAY EQP 从 Sheet 整机 OUT 履历取设备；ARRAY CHAMBER 优先取 Sheet 子单元 OUT 履历并回退 Sheet 单元履历。
- [x] OLED/TP EQP 从 Glass 整机 OUT 履历取设备；TP CHAMBER 从 Glass 子单元 OUT 履历取腔室。
- [x] OLED CHAMBER 通过 OLED 工序映射表匹配归一化主工序，包含 `21200-CVD1`～`21200-CVD4` 到 `21200-CVD` 的兼容逻辑。
- [x] 履历仅使用 `INOUT_TYPE='OUT'`，查询范围从报表开始日前推一个月到报表结束日；每条量测选取不晚于量测时刻的最近记录，并遵守 ARRAY 子单元优先级。
- [x] 返回点位明细保留产品、厂别、检测站点、参数、点位测量值与量测时间，并新增主站点、路由类型、追溯设备/腔室和追溯来源；点位数量不因履历多行而增加。
- [x] 第二幅图明确按主站点设备/腔室分组并排序；第三幅图仍按量测过货时间排序，第一幅图和能力表不变。
- [x] 缺失规格按当前站点 + EQP 回退；EQP 履历缺失回退量测设备；CHAMBER 履历缺失显示 `UNKNOWN`，且均不导致页面异常。
- [x] SPC 快照结构策略升级，旧快照缺少新追溯字段时触发刷新；数据库失败时仍遵守现有快照降级边界。
- [x] `references/domain/spc/spec-data_source.md` 完整记录每个展示字段、规格路由、各厂履历来源、时间口径、选择规则和探查证据。
- [x] 单元、集成与页面 E2E 覆盖主路由、回退、最近 OUT 去重、图表分组及现有筛选回归；项目 SPC smoke 通过。
