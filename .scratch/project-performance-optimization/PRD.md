# 项目性能优化：快速反馈与 CPM 等价加速

Category: `enhancement`  
Status: `ready-for-human`  
Created: `2026-07-14`

## Problem

项目更新后的反馈周期过长。目前默认验证入口会收集整个单元测试目录，重依赖导入和测试收集占据大部分墙钟时间；在当前电脑上，可运行单元测试基线约为 11.64 秒，而 SPC 定向测试约为 1.73 秒。完整收集还会遇到一个既有的过期导入错误，使“小范围修改后的快速烟测”和“完整回归”无法清晰区分。

运行期也存在可测量的纯计算热点。以仓库内约 104 万条真实 SPC 点位数据和约 9.3 万条派生 Sheet 特征的数据形状为基准，周期能力报表使用 Sheet Mean sigma 时约需 2.01 秒，使用 Point Value sigma 时约需 6.10 秒。当前实现会为月、周、日重复扩展数据，并在 Pandas 分组之后再次进入 Python 逐组循环。

性能问题不能通过修改业务口径解决。周期选择、CPM/CPK 公式、sigma 来源、空值处理、分组维度、首个有效规格值、样本计数和输出排序均为不可变行为合同。

## Solution

建立两个可独立验证、独立回滚的性能切片：

1. 提供显式领域参数的快速烟测入口。开发者选择 SPC、Yield、Equipment 或完整单元测试；每个领域映射到现有测试文件，默认行为保持保守，完整验证入口继续存在。快速烟测只优化反馈路径，不宣称代替完整回归。
2. 将 CPM 周期能力的逐组 Python 计算改写为 Pandas 聚合/合并形式，减少解释器循环和中间对象，同时保持现有公开接口、字段、排序、公式、窗口和 fallback 行为。

所有性能结论同时提供“优化前输出合同、优化后等价性测试、真实数据形状基准”。若某一切片不能通过其风险测试，单独撤回该切片。

## User Stories

### 开发者快速反馈

- 作为只修改 SPC 代码的开发者，我可以显式运行 SPC 烟测，而不必收集无关领域测试。
- 作为修改 Yield 或 Equipment 的开发者，我可以使用相同入口选择对应领域，避免记忆多个命令。
- 作为修改共享基础设施的开发者，我能选择完整单元测试；工具不会把共享变更自动误判成安全的小范围变更。
- 作为维护者，我可以看到烟测实际执行的测试目标，避免“看似通过但不知道测了什么”。
- 作为发布者，我仍可以运行完整回归；快速烟测不会改变或删除完整验证入口。
- 作为维护者，当测试文件被重命名或映射失效时，我会得到明确失败，而不是零测试假通过。

### 报表用户运行体验

- 作为 CPM 报表用户，我在相同数据和筛选条件下得到与优化前相同的月/周/日能力记录。
- 作为使用 Sheet Mean sigma 的用户，我得到相同的均值、标准差、CPM、CPK、样本数、规格限和排序。
- 作为使用 Point Value sigma 的用户，我得到相同的点位标准差和 point count；缺少点位统计时仍回退到 Sheet Mean。
- 作为查看稀疏数据的用户，我仍能看到单样本标准差为 NaN、缺失控制限/target 的既有处理结果。
- 作为查看跨月、跨周和非连续日期数据的用户，我仍得到“最近有数据的周期”而非连续日历周期。
- 作为页面使用者，我不感知新的缓存语义、刷新语义、字段变化或业务规则变化。

### 维护与风险控制

- 作为维护者，我可以分别回滚烟测架构切片和 CPM 算法切片。
- 作为维护者，我可以从 Issue 和最终风险清单追踪每个潜在业务/功能风险及对应测试。
- 作为维护者，我可以比较同一数据形状下的前后墙钟时间；没有显著收益的算法改动不会保留。
- 作为维护者，既有测试故障会作为基线缺陷记录，不会通过改变业务行为来“顺便修复”。

## Implementation Decisions

- 快速烟测采用显式领域选择，不依据未提交 Git 变更自动猜测影响范围。
- 快速烟测复用现有测试，不复制业务断言；完整单元测试保持独立入口。
- CPM 优化只发生在 core 聚合内部，应用服务、Streamlit cache payload、ViewModel 和页面消费合同保持不变。
- 等价性比较覆盖列集合、行顺序、值、dtype 可接受差异、NaN/NaT、正负无穷以及浮点容差；公式本身不改写。
- 真实数据基准使用只读本地快照，不把快照或敏感数据写入测试产物。
- 每个切片必须满足正确性门禁后才比较速度；正确性失败时不以速度作为保留理由。

## Testing Decisions

- 快速烟测入口使用单元测试验证领域到测试目标的映射、默认保守行为、无效领域错误和空目标失败。
- 记录 SPC 快速烟测与完整单元基线的墙钟时间，并验证输出中明确列出所执行目标。
- CPM 先增加公开函数级特征测试，覆盖：空数据、缺列、NaN 分组键、非连续周期、单样本、首个非空规格/控制限/target、Point Value sigma、fallback、排序和数值边界。
- 使用固定输入保存优化前结果，在实现后执行 DataFrame 等价比较。
- 使用真实快照数据形状运行前后基准；目标是 CPM Point Value 路径获得有意义的墙钟下降，同时不增加不可接受的峰值内存。
- 最后按风险清单逐项运行测试。无法证明安全的 Issue 切片整体撤回。
