## What to build

在不改变公开函数签名和结果合同的前提下，将 CPM 月/周/日周期能力计算中的 Python 逐组循环改为 Pandas 聚合与合并，减少中间对象和解释器开销。Sheet Mean 与 Point Value sigma 路径都必须等价；Point Value 缺失时继续逐组回退 Sheet Mean。

## Acceptance criteria

- [x] 公开周期能力函数的参数、返回列、行顺序和调用方不变。
- [x] 最近 2 个有数据月份、3 个有数据周、7 个有数据日的选择与 period sort 不变。
- [x] 分组维度、`dropna=False`、有效行条件、`std(ddof=1)`、Sheet 唯一计数和 Point count 不变。
- [x] `usl`/`lsl`、`ucl`/`lcl`、`target` 使用组内首个有效值；target 缺失时仍取规格中点。
- [x] Point Value sigma 有统计时使用点位标准差；无统计/无有效值时回退 Sheet Mean，并保持 `sigma_source` 和 `point_count` 语义。
- [x] CPM/CPK 公式、NaN、NaT、单样本、零标准差、无穷值和浮点容差行为不变。
- [x] 优化前后固定输入 DataFrame 通过等价比较，既有 CPM 测试全部通过。
- [x] 仓库真实 M626 数据形状上，Point Value 路径相对 6.10 秒基线至少快 30%；否则撤回本 Issue。
- [x] 不修改 Streamlit cache、应用服务、数据库、快照、页面和业务配置。
