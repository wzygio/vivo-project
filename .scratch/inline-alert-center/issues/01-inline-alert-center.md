# Inline 自动预警中心：单片异常 + 趋势波动（含异常项图像自动展示）

Category: `enhancement`  
Status: `ready-for-agent`  
Created: `2026-08-25`  
Source: `docs/dev_docs/dev_spec/Inline_domain/feat-alert_center.md`；PRD：`docs/PRD/PRD-2026-08-25-Inline自动预警中心.md`  
Related: `docs/ADR/0001-streamlit-cache-native-payload-boundary.md`、ADR-0014/0016（shared 提取约束）、`.scratch/cpm-cpk-alert/`（CPK 预警先例）

## Current context

- `src/inline_domain` 四个子模块（spc、ctq、aoi_tt、aoi_rs）的 OOS 修饰逻辑已把超规片持久化到 `resources/` 下各自工作簿；**每行本来就是超规片**，`flag` 三态语义为 True=默认截断修饰、False=用户确认释放真实值、Delete=删除该行（`src/inline_domain/core/shared/sheet_oos_decoration.py`）。
- 工作簿结构差异：spc/ctq 含 `sheet_start_time`（datetime64）；aoi_tt 时间列名为 `start_time`；**aoi_rs 无任何时间列且文件被企业加密**，读取必须走 `load_sheet_oos_decoration` 的 COM 回退。
- SPC 页面已有完整预警模板：`build_weekly_cpk_alerts` / `render_cpk_alert_center` / `filter_spc_report_by_alerts` / `render_cpk_alert_indicator_sections`（`app/sections/inline_domain/spc/spc_dashboard.py:67-590`），含 Expander、`RenderGate.collect_memoized` 两阶段渲染与独立 chart key 前缀；其余三个 inline 页面无预警 UI。
- Yield 页面已有预警中心（`app/components/alert_center.py`）：Lot 超规扫描（`compute_lot_oos_records`）与良率波动判定（`AbnormalDetector`，环比翻倍且>0.1% 或绝对激增>0.2%），但告警仅返回 `List[str]` 文本，**没有异常项自动展示图像能力**；按 Defect Code 出图的紧凑渲染入口 `_build_compact_render_payload` + `render_code_compact_expanders` 已存在（`app/sections/yield_domain/yield_dashboard.py`）。
- 项目无共享"ISO 上一周"工具；`tools/generate_ppa_oos_weekly_summary.py:previous_calendar_week` 返回半开区间 `[上周一 00:00, 本周一 00:00)`，是现成范式。

## Desired outcome

- SPC / CTQ / AOI_TT / AOI_RS 四个监控报表页面与入库不良率分析看板，均在筛选器上方提供"预警中心"Expander：展示**上一 ISO 周**（`[上周一 00:00, 本周一 00:00)`）的预警，有警自动展开，无警显示正常态，数据不可用显示降级提示且不阻断报表主体。
- 单片异常口径（已与需求方确认 D1）：仅 `flag=FALSE` 的记录。spc/ctq 消费 ViewModel 已有修饰结果，aoi_tt/aoi_rs 读取工作簿（列名归一化 + COM 回退）。
- 趋势波动：SPC 复用既有 CPK 预警（cpk<1.33、上一周、未修饰）不回归；Yield 复用 `AbnormalDetector` 判定。
- 所有命中异常项的图像自动渲染在独立 Expander 中（参考 CPK 预警的 `🚨 自动预警指标图像`），按预警指标键（spc/ctq: factory+step_id+param_name；aoi_tt: +tt_name；aoi_rs: +rs_code；yield: Defect Code）精确过滤，无需用户手动筛选。
- 渲染遵循 `RenderGate` 两阶段：payload 集中计算后集中渲染；memo 签名含产品缓存 revision；预警区 chart key 使用独立前缀避免与手动筛选区冲突。
- aoi_rs 修饰写入改造（已与需求方确认 D2）：明细新增 `sheet_start_time` 列；历史无时间行不参与预警。

## Acceptance criteria

- [x] 五个页面均出现预警中心 Expander；有预警自动展开，无预警显示成功/空态，数据不可用显示 info 且不阻断报表。
- [x] 单片异常表内容 = 当前产品明细中 `flag=FALSE` 且时间 ∈ 上一 ISO 周的记录；`flag=Delete` 行与时间为空/解析失败的行不参与；aoi_tt 的 `start_time` 被正确归一化。
- [x] ISO 上一周边界正确（含跨年初 ISO 周）；以页面默认 end_date 为参考日。
- [x] SPC 既有 CPK 预警行为无回归（判据、展示、展开逻辑不变）。
- [x] 命中异常项图像出现在自动预警图像 Expander 中，指标键过滤精确（不多图、不漏图）；预警区与手动筛选区可同时操作无 plotly key 冲突。

- [x] aoi_rs 新写入的修饰明细带 `sheet_start_time`；合并键列不变；旧读取方不受影响。
- [x] 点击"刷新缓存/刷新数据"后预警与图像正确重建；普通 rerun 命中缓存，不重复读取工作簿/启动 COM。
- [x] 预警计算只读，不触发任何工作簿重写。
- [x] 单元测试（ISO 周边界、flag 三态、时间归一化、键过滤、结构化记录与文本一致性、aoi_rs 时间列）与 E2E 测试（五页 Expander 存在性与展开行为）全部通过。

## Out of scope

- 不修改 OOS/CPK/良率波动任何判定阈值与算法；不改变 flag 三态语义与修饰写盘时机（除 aoi_rs 新增时间列外）。
- 不新增预警推送、邮件、持久化工单、确认/关闭工作流或阈值配置界面。
- 不改造 monitor 自动预警看板页（`monitor_dashboard.py`）。
- 不重构既有 CPK 预警与 Yield 预警中心的判定逻辑。
- 不迁移 aoi_rs 历史数据的时间值。

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement  
**Summary:** 为四个 Inline 监控报表与入库不良率看板增加上一 ISO 周自动预警（单片异常 flag=FALSE + 趋势波动），并把命中异常项的图像在独立 Expander 中自动渲染，全程遵循 RenderGate 两阶段渲染。

**Current behavior:**

- 四个 sheet OOS 工作簿已持久化超规片明细（每行均为超规片；flag 三态 True/False/Delete），但仅 SPC 页有 CPK 预警 UI，其余三页无预警；Yield 页有文本预警中心但无异常项自动出图。
- aoi_rs 工作簿无时间列且被企业加密；aoi_tt 时间列名为 `start_time`；spc/ctq 为 `sheet_start_time`。
- SPC 已有完整可复用模板（`app/sections/inline_domain/spc/spc_dashboard.py:67-590`）；Yield 的紧凑组图入口 `_build_compact_render_payload` 已存在；`RenderGate` 两阶段机制已就绪。

**Required behavior:**

- 共享纯函数：`previous_iso_week_range(reference_date)` 返回 `[上周一 00:00, 本周一 00:00)`；`build_sheet_oos_alerts(detail_df, time_column=..., reference_date=...)` 筛 `flag==FALSE` 且时间落在上一周的记录（时间 `pd.to_datetime(errors="coerce")` 归一化，失败行排除）。落 `src/inline_domain/core/shared/`。
- 各模块指标键：spc/ctq = (factory, step_id, param_name)；aoi_tt = (factory, step_id, tt_name)；aoi_rs = (factory, step_id, rs_code)；yield = Defect Code。
- spc/ctq 单片异常消费 ViewModel 已有修饰结果；aoi_tt/aoi_rs 用 `load_sheet_oos_decoration` 读工作簿（mtime 入缓存键，失败降级为 info，不阻断页面）。
- 前端共享预警中心 UI 落 `app/sections/inline_domain/shared/alert_center.py`；四页各自接线"预警中心 Expander（有警自动展开）+ 自动预警图像 Expander（复用各页既有 indicator sections 渲染函数，独立 chart_key_prefix）"。
- Yield：`AbnormalDetector` 新增结构化记录方法（level/defect_group/defect_desc/period/curr/prev/rule），现有 `List[str]` 接口输出不变；页面新增"🚨 自动预警缺陷图像"Expander，对趋势波动+Lot 超规命中的 Defect Code 去重出图（`_build_compact_render_payload` + `collect_memoized`，key 前缀 `yield_alert`）。
- aoi_rs：`core/aoi_rs/aoi_rs_decoration.py` 明细新增 `sheet_start_time` 列（sheet 图取 sheet start_time，lot 图取 lot 最早 start_time）；合并键列不变；历史空值不参与预警。
- 预警只读，不触发工作簿重写。

**Key interfaces:**

- `previous_iso_week_range(reference_date) -> tuple[pd.Timestamp, pd.Timestamp]`
- `build_sheet_oos_alerts(detail_df, *, time_column: str, reference_date) -> pd.DataFrame`
- `render_sheet_oos_alert_center(alerts_df, *, title, module_label)`（shared UI）
- `filter_report_by_alert_keys(df, alerts_df, key_map) -> pd.DataFrame`
- `AbnormalDetector` 新结构化方法（返回记录列表/DataFrame，文本方法由其格式化派生或保持双轨但口径一致）

**Edge cases:**

- 跨年初 ISO 周（如 2026-W01 的上一周属于 2025）；空明细表；flag 为 Delete/空值；时间解析失败或缺失（aoi_rs 历史行）；加密工作簿 COM 读取失败降级；预警键在报表数据中无匹配（不多图不漏图）；plotly key 冲突。

**Verification expectations:**

- 单元测试覆盖上述纯函数全部分支与边界、结构化记录与文本一致性、aoi_rs 时间列写入。
- 集成测试：临时工作簿模拟上周/本周/上上周记录筛选。
- E2E（tests/e2e/，Playwright）：五页 Expander 存在性与展开行为；SPC CPK 预警无回归。
- 回归：SPC/CPM 既有测试套件通过；缓存遵守 ADR-0001 原生 payload 边界。
