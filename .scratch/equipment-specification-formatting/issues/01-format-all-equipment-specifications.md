# 格式化全部关键备件寿命规格

Category: `enhancement`  
Status: `ready-for-agent`  
Created: `2026-07-15`

## Current context

- 源工作簿包含主规格 Sheet“关键备件寿命规格”（132 条源记录，13 列）；其关键字段顺序不同于报表基线，并且覆盖 Array、OLED、TP 三个厂别。
- 目标参考基线在 Excel 中为 270 条扁平记录，列顺序固定为：厂别、备件类型、设备类型、膜层、制程、寿命规格、站点、机台号-腔室、参数名称。文件本身受企业加密保护，不能当作普通文本 CSV 直接用 Pandas 读取。
- 当前规格 CSV 生成逻辑只对站点、机台号-腔室按换行展开；不能解析如 `3AFS03/04/05/11 PM4/PM5` 的缩写，无法生成完整的设备-腔室组合。
- 源表中 38 条记录含多站点、60 条记录含复杂机台表达式，且 116 条记录的参数名称为空；参数名称为空是允许的目标格式。
- 源表另有 72 条记录未提供站点或机台-腔室；参考表两列均为非空，因此这些不可监控记录需保留到独立诊断产物，而不能伪造为可查询规格行。
- 当前 Streamlit 缓存边界与数据库快照/匹配流程不应因本格式化能力改变。

## Desired outcome

- 系统能从“关键备件寿命规格”读取全部规格，并生成一份独立于参考基线文件的 UTF-8 BOM CSV。
- 该输出具有与参考基线相同的九列表头、列顺序和扁平粒度：每行仅保留一个站点和一个“机台号-腔室”组合；参数名称可为空。
- 站点按换行拆分；机台字段先按换行分组、再拆分设备与腔室、最后扩展斜杠缩写为全部有效组合。

## Acceptance criteria

- [ ] 输出 CSV 的列名和列顺序严格为：厂别、备件类型、设备类型、膜层、制程、寿命规格、站点、机台号-腔室、参数名称。
- [ ] 主规格 Sheet 的每条有效源记录均被处理；源表的辅助列不出现在输出中，字段按名称映射而非依赖源列顺序。
- [ ] 单条或多条换行站点被拆成单值；同一源记录的每个站点均与其有效机台-腔室组合形成独立行。
- [ ] 机台表达式支持以空白或连字符分隔设备和腔室，支持以 `/` 省略共享前缀的设备或腔室编号，并生成完整笛卡尔组合；例如 `3AFS03/04/05/11 PM4/PM5` 生成 8 个组合。
- [ ] 已带有完整 `设备-腔室` 形式的值保持不变；参数名称为空时输出空字符串而非删除该规格。
- [ ] 已知的 `{腔室}_TRGTLIFE_G_MAX`、`{腔室}_MASKLIFE_G_MAX`、`{PMX_3}_PRE_SPRT_KWH` 分别规范化为参考表兼容的 LIKE 模式；其他空参数名称保持为空。
- [ ] 缺少站点或机台-腔室的源记录不进入主规格表，但在独立诊断产物中保留源行标识、关键字段和排除原因。
- [ ] 格式化产物写入新的明确路径，不覆盖 `resources/critical_parts_baseline.csv` 或源工作簿。
- [ ] 企业加密的源/参考文件可经受管 Excel 读取路径处理；输出可被 `pandas.read_csv(..., encoding="utf-8-sig")` 读取。
- [ ] 自动化测试覆盖列契约、换行展开、斜杠前缀继承、笛卡尔展开、空参数名称、无效/空机台值和不覆盖参考文件。
