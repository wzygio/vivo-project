## Current context

- AOI_RS 报表已交付（issue 01）：月周天趋势图为按 Code 分线的比值线图，By Lot / By Sheet 为点线图，按（厂别+站点）分组渲染，组内所有选中 Code 共线展示。
- `core/aoi_rs/aoi_rs_calculator.py` 的 `build_period_trend_df` 已产出每 period 的 `sheet_qty`（过货分母），但仅在 Code 有分子的 period 才有行；无独立的“全 period 过货量”数据。

## Desired outcome

1. 月周天趋势图增加每个时间段的过货量，以**柱状图**展现（与比值线双 Y 轴）。
2. 月周天趋势图中月度、周度、日度在视觉上区分开（用简单方法：分组留白 + 分组配色）。
3. 多选 Code 时，针对**每个 Code 分别绘制**三张图（月周天趋势 / By Lot / By Sheet），不再共线：
   - 每个 Code 一个 Expander，默认展开；
   - 三幅图在 Expander 中并列排布。

## Acceptance criteria

- [x] 趋势图每个 period 显示过货量柱（含该 Code 无 RS 数据的 period，柱子来自同站点分母数据），与比值线双 Y 轴不互相压扁。
- [x] 月/周/天三组在 x 轴上有明确视觉分隔（组间留白 + 柱状按组配色）。
- [x] 选中多个 Code 时，每个 Code 一个默认展开的 Expander，内含并列的三张图；不同 Code 的数据不混在同一坐标系。
- [x] 单 Code、无规格、分母为 0、空数据等既有边界行为不回归。
- [x] 既有自动化测试适配后全绿，inline_domain 无回归；完成 Streamlit E2E 复验（多 Code 场景）。

## Out of scope

- 不改变三张图的计算口径（比值、Σcode_qty、规格线 type_flag 映射不变，ADR-0007 仍然有效）。
- 不改动筛选交互、时间窗、数据源。

## Questions to resolve

- [x] Expander 粒度：同一 Code 可能跨站点出现，按（站点 + Code）展开，标题含站点与 Code 中文名（用户确认按任务字面“每个 Code”执行，站点保留在标题中以维持口径正确）。
