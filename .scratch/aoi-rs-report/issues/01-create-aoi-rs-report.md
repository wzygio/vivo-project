## Current context

- 系统已有 SPC 监控报表（`app/pages/SPC监控报表.py`）和 CTQ 监控报表，二者共享 `inline_domain` 的应用服务/物理仓储模式：页面 → 应用服务（缓存 payload → ViewModel）→ 仓储/data_loader（厂别三元组 UNION ALL 查询）→ Dashboard 渲染筛选与图表。
- 已完成任务文档 Workflow 前三步：逻辑链分析、数据需求梳理、数据库探查，结论固化在 `references/domain/aoi_rs/spec-data_source.md`。
- 数据源全部确认：RS 明细表 `eda.spc_tzbjx_rs_{array,oled,tsp}`（含 `lot_id`、`rs_code`、`code_qty`、`step_id`、`product_spec`）；过货分母视图 `eda.spot_eda_array_view_sht_v` / `spot_eda_oled_view_gls_v` / `spot_eda_tp_view_gls_v`；规格表 `mdw.dwd_imp_rs_code_xishu_fo_tzsbjx`（按 `type_flag` 区分图类型，`code_desc` 提供 Code 中文名）；产品字典 `mdw.dwr_mes_productspec`。
- 月周天"跳过空值向前补全"切分逻辑已存在于 `src/inline_domain/core/spc/spc_calculator.py` 的 `build_available_period_axis`（最近 2 月/3 周/7 天非空数据）。
- Streamlit 缓存边界受 ADR-0001 约束：缓存函数只返回 DataFrame/原生容器/标量，ViewModel 在缓存外构造。

## Desired outcome

- 新增独立的 AOI_RS 报表页面，Streamlit 可自动发现，Header、产品切换、缓存刷新与既有报表一致。
- 页面固定时间范围为"上一自然月 1 日 ~ 当前日期（含当天）"，不提供时间筛选框。
- 报表包含三张图：
  1. By 月周天趋势图（两月、三周、七天，跳过空值向前补全）：每个 period 的值 = 该 period Σ`code_qty` ÷ 该 period 过货 distinct sheet/glass 数，按 RS Code 分线，叠加 `MWD_RATIO` 规格线。
  2. By Lot 别点线图：每个 Lot 的 RS 个数（Σ`code_qty`），叠加 `LOT_RATIO` 规格线。
  3. By Sheet 别点线图：每个 sheet/glass 的 RS 个数（Σ`code_qty`），叠加 `SHEET_ID`/`GLASS_ID` 规格线。
- 筛选框为厂别、站点、Code 名称（rs_code + code_desc），交互与 SPC 页面一致（查询按钮门控）。
- 数据颗粒度：产品型号 → 厂别 → 站点 → RS Code → RS 个数（明细）。
- 后端位于 `inline_domain` 下独立的 aoi_rs 子模块，产品过滤统一走 `product_spec` join `mdw.dwr_mes_productspec`（array 表 `productcode` 为空，不可用）。

## Acceptance criteria

- [x] 新页面可由 Streamlit 独立发现并打开，Header/产品切换/缓存刷新行为与 SPC 页面一致；页面无时间筛选框，默认窗口为上一自然月 1 日至当前日期。
- [x] 月周天趋势图：分母为过货视图同站点同 period 的 distinct sheet/glass 数，分子为该 period Σcode_qty，比值按 RS Code 分线展示；period 轴为最近 2 月/3 周/7 天的非空数据（跳过空值向前补全）；`MWD_RATIO` 规格线正确叠加。
- [x] By Lot 与 By Sheet 点线图分别按 `lot_id`、`sheet_id`/`glass_id` 聚合 Σcode_qty，并叠加对应 type_flag（`LOT_RATIO`、`SHEET_ID`/`GLASS_ID`）的规格线。
- [x] 筛选框厂别（ARRAY/OLED/TP）、站点、Code 名称选项来自数据本身；未点查询或查询后改动筛选时不渲染报表（与 SPC 门控一致）。
- [x] 三厂数据经统一逻辑模型（factory/id 字段/时间字段三元组）UNION ALL 加载，产品过滤经 product_spec join 产品字典；OLED 表 `code_qty=0` 记录按加和口径自然计入（不改变分母）。
- [x] 空数据、无规格、单边规格、无筛选结果时安全显示明确状态，不抛异常。
- [x] 缓存只返回原生 payload（ADR-0001），Header 刷新可使缓存失效。
- [x] 以 RED→GREEN 自动化测试覆盖数据加载契约、period 聚合（含分母为 0）、规格匹配、筛选门控与页面渲染，SPC/CTQ 回归不受影响，并完成 Streamlit 页面 E2E 烟测。

## Out of scope

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement  
**Summary:** 新增独立 AOI_RS 监控报表，复用 SPC/CTQ 链路模式，数据源为三张 RS 明细表 + 三张过货视图 + RS 规格表，全部已探查确认。

**Current behavior:**

系统只有 SPC（连续测量值 + CPM/CPK）与 CTQ 两类 Inline 监控报表，没有 AOI RS 复判数据的报表入口。RS 数据（AOI 缺陷点位的复判 Code 计数）已存在于 `eda.spc_tzbjx_rs_{array,oled,tsp}`，规格存在于 `mdw.dwd_imp_rs_code_xishu_fo_tzsbjx`，但无任何应用服务、页面或图表消费它们。

**Desired behavior:**

系统提供独立 AOI_RS 页面（`app/pages/` 下自动发现）。固定时间窗为上一自然月 1 日至当前日期，无时间筛选框。渲染三张图：①月周天趋势图（最近 2 月/3 周/7 天非空 period，值 = Σcode_qty ÷ 过货 distinct sheet/glass 数，按 RS Code 分线，叠 `MWD_RATIO` 规格线）；②By Lot 点线图（按 lot_id 聚合 Σcode_qty，`LOT_RATIO` 规格线）；③By Sheet 点线图（按 sheet_id/glass_id 聚合，`SHEET_ID`/`GLASS_ID` 规格线）。筛选框为厂别、站点、Code 名称（rs_code+code_desc），查询按钮门控与 SPC 一致。

**Key interfaces:**

- AOI_RS 查询配置：prod_code + 固定时间窗（上一自然月 1 日 ~ 当前），可选 factory/step_id/rs_code 过滤。
- 数据加载：厂别三元组（ARRAY→`spc_tzbjx_rs_array`/`sheet_id`/`sheet_start_time`；OLED→`spc_tzbjx_rs_oled`/`glass_id`/`glass_start_time`；TP→`spc_tzbjx_rs_tsp`/`glass_id`/`glass_start_time`）UNION ALL；产品过滤统一 `LEFT JOIN mdw.dwr_mes_productspec ON productspecname = product_spec` 按 `productcode = prod_code`（**不用** RS 表自带的 productcode 列，array 全空）。
- 分母加载：`eda.spot_eda_array_view_sht_v` / `eda.spot_eda_oled_view_gls_v` / `eda.spot_eda_tp_view_gls_v`（注意 TP 非 tsp），按 step_id + 时间窗过滤后 COUNT(DISTINCT id)。
- 规格加载：`mdw.dwd_imp_rs_code_xishu_fo_tzsbjx`，粒度 prod_code+factory+step_id+rs_code+type_flag，按图类型取 `MWD_RATIO`/`LOT_RATIO`/`SHEET_ID`/`GLASS_ID` 的 spec 作单边上限线；`code_desc` 供 Code 名称筛选与图例。
- Period 切分：复用 `src/inline_domain/core/spc/spc_calculator.py` 的 `build_available_period_axis`（跳过空值向前补全），不新写切分逻辑。
- 缓存 payload：仅 DataFrame/原生类型（ADR-0001），ViewModel 在缓存外构造；页面缓存签名模式照抄 SPC/CTQ 页面。
- 统一逻辑模型：factory / prod_code / sheet_id（glass 归一命名）/ lot_id / step_id / rs_code / code_qty / start_time。

**Edge cases:**

- 分母为 0（某 period 无过货）时该 period 值记为空/跳过，不得除零抛异常。
- 无规格、无筛选结果、空数据时显示明确空状态。
- OLED 表约 40% 记录 `code_qty=0`，按加和口径自然计入分子，不影响分母。
- rs_code 存在个别 6 位代码（如 C4PCP3），不做长度假设。
- RS 明细 product_spec 存在脏值（'1'、'55'），join 不上产品字典即被排除。

**Out of scope:**

- 修改 SPC/CTQ 行为、CPM/CPK、共享 period 切分语义；新增数据库表；AOI（非 RS）报表。

**Verification:**

- RED→GREEN 单元/集成测试：数据加载契约（含产品 join、厂别三元组）、period 聚合与分母为 0、规格 type_flag 匹配、筛选门控、页面渲染顺序。
- SPC/CTQ 定向回归全绿。
- Streamlit E2E 烟测：页面可打开、三图渲染、筛选与查询门控可用、产品切换与缓存刷新正常。
