## Current context

- `app/sections/inline_domain/` 下四个报表 section：`spc`（1215 行）、`ctq`（283 行）、`aoi_rs`（502 行）、`aoi_tt`（499 行）。
- `ctq_dashboard.py:13-18` 从 `spc_dashboard` 导入 `_create_period_overview_chart`、`_create_sheet_points_box_charts`、`_resolve_chart_type`、`render_sheet_oos_decoration_admin` 等符号，形成跨模块私有依赖。
- 已核实缺陷：`ctq_dashboard.py:270` 以 `(indicator_features_df, indicator_raw_df)` 调用 spc 的 `_resolve_chart_type(param_name, line_param_name_contains)`，签名错配；对 DataFrame 迭代得到列名，列名必出现在 `str(df)` 中，CTQ 图表类型实际恒为 line。配置 `config/inline_config.yaml` 的 `spc.chart.line_param_name_contains=["UNI"]` 在 CTQ 路径上从未生效。
- 筛选逻辑四份复制：`_unique_sorted`、`_normalise_selection`、`_filter_signature`、`get_available_factories`、`get_steps_for_factory`、级联筛选面板（厂别切换清空、站点变更自动全选、查询签名门控）、`filter_*_report`。
- aoi_rs/aoi_tt 大面积逐字重复：常量（`CODE_PALETTE`、`PERIOD_BAR_COLORS`、`PERIOD_TYPE_NAMES`、`_PERIOD_SEPARATORS`）、`_add_spec_trace`、月周天趋势图、By Lot/By Sheet 点线图。
- 页面侧消费方：`app/pages/{SPC监控报表,CTQ监控报表,AOI_RS监控报表,AOI_TT监控报表}.py` 按现有公开函数名导入；测试位于 `tests/unit/app/sections/{spc,ctq,aoi_rs,aoi_tt}/` 与 `tests/unit/app/pages/`。
- 后端已有 shared 先例：`src/inline_domain/core/shared/`、`src/inline_domain/application/shared/`。
- 既有测试基线：`tests/unit` 存在少量既有失败（yield_global_data_policy、code_selector_filter 等），不得新增失败。

## Desired outcome

- 新增 `app/sections/inline_domain/shared/` 包（constants / filters / chart_type / spec_lines / sheet_charts / aoi_charts + 包级公共 API），统一承载：级联筛选、折线/箱线决策（配置驱动）、规格线绘制（LSL 为空或 0 仅绘上限）、月周天与 By 过货时间（时间轴）图表、AOI 趋势/点线图。
- 四个 dashboard 保留现有公开函数名与签名（页面与测试导入路径不变），内部委托 shared；`ctq` 不再导入 `spc_dashboard`。
- CTQ 图表类型修复为与 SPC 同口径：`resolve_chart_type(param_name, tokens)`；参数名含 `UNI` → line，否则 box。
- 除上述 CTQ 修复外，四个页面渲染行为、session key、图表结构、文案不变。

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement  
**Summary:** 新建 `app/sections/inline_domain/shared/` 包承载四个 inline 报表 section（spc/ctq/aoi_rs/aoi_tt）的公共筛选与绘图管线；四个 dashboard 保留公开 API 并委托 shared；同时修复 CTQ 图表类型解析签名错配缺陷。

**Current behavior:**

- ctq 跨模块导入 spc 私有函数；CTQ `_resolve_chart_type` 调用签名错配导致图表类型恒为 line，配置 `spc.chart.line_param_name_contains=["UNI"]` 在 CTQ 路径不生效。
- 筛选逻辑（级联选项推导、签名门控、report filter）在 spc/ctq、aoi_rs/aoi_tt 之间逐字重复；AOI 双模块的趋势图/点线图/规格 trace/常量大面积重复。

**Required behavior:**

- `shared/` 子模块划分：`constants`、`filters`、`chart_type`、`spec_lines`、`sheet_charts`、`aoi_charts`，包级 `__init__.py` 显式 re-export。
- 公开行为不变（除 CTQ chart_type 修复）：session key 前缀、图表结构、文案、页面 import 路径全部保持。
- CTQ chart_type 修正为 `resolve_chart_type(param_name, tokens)`，与 SPC 同口径共用配置。

**Key interfaces:**

- `shared/filters.py`：`unique_sorted`、`normalise_selection`、`filter_signature`、`get_available_factories`、`get_steps_for_factory`、第三级选项（列名参数化）、`render_cascade_filters(key_prefix, ...)`、`apply_report_filter(...)`。
- `shared/chart_type.py`：`CHART_TYPE_BOX`/`CHART_TYPE_LINE`、`resolve_chart_type(param_name, line_param_name_contains)`。
- `shared/spec_lines.py`：规格值格式化、首行规格提取、规格线绘制（LSL 空/0 → 仅上限）、y 轴范围推导。
- `shared/sheet_charts.py`：月周天分布图、Sheet 点位图（By 腔室 / By 过货时间，line 时横轴 `type="date"`）。
- `shared/aoi_charts.py`：spec trace 工具、月周天趋势图、By Lot/By Sheet 点线图；规格线经 spec_provider 回调注入（RS 单值 / TT USL+UCL）。
- 配置读取留在调用方组合层注入，shared 纯函数不读 `ConfigLoader`、不依赖 `st.session_state`。

**Edge cases:**

- LSL 为空 / LSL=0 / 极小值科学计数格式化（既有 ctq 测试覆盖，须保持）。
- 空 DataFrame、缺列（`param_value`、`sheet_start_time`、`main_process_unit_id` 缺失）按现有降级路径原样保留。
- AOI spec_provider：规格缺失（None/NaN）不画规格线；RS 按 chart_kind 区分规格；TT 双上限可单边缺失。
- session key 前缀参数化传入，禁止在 shared 内硬编码。

**Verification expectations:**

- 新增 `tests/unit/app/sections/shared/` 单测；现有 sections/pages 单测不修改即通过。
- `pytest tests/unit -q` 不引入新失败（既有基线：yield_global_data_policy ×2、code_selector_filter ×2 等）。
- 无 E2E（用户自行验收）；四个页面 import smoke 通过。

**Out of scope:**

- monitor/equipment/yield 共享化、E2E、性能优化、后端 `src/` 改动、布局配色文案变更。
