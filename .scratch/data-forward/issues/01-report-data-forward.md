# 报表制造事实时间统一前推四天

## Current context

- 当前系统没有统一的源时间/显示时间策略，各域直接把数据库或 Parquet 中的制造事实时间交给应用层。
- Yield、共享 Inline 测量和 AOI_RS 使用产品级 Parquet 快照；Q-Time 与 IJP 按页面窗口直接查询；Equipment 对真实测量先执行三天新鲜度判断并用仿造快照补缺。
- 共享 Inline 与 AOI_RS 的三个月快照起点使用“截止日减三个月的同日”，不满足自然月月初窗口。
- 页面、应用服务、人工修饰和聚合依赖仓储返回的时间列。直接改写持久化快照会造成重复平移、开关切换污染和旧快照迁移风险。
- ADR-0001 要求缓存跨越原生 payload，ADR-0012/0015 分别规定共享 Inline 与 AOI_RS 的原始快照边界；本功能必须保持原始事实快照，不把显示日期持久化为源事实。

## Desired outcome

- 通过全局开关统一控制客户显示日期：开启时，显示时间等于源时间加四天；关闭时保持真实日期。
- 页面查询条件始终按显示时间解释，仓储负责换算源查询窗口、平移制造事实时间并按原区间语义二次过滤。
- 产品级原始快照全量窗口从截止日往前第三个月的第一天开始，到截止日结束；快照仍保存真实时间。
- Yield、Inline、Indicator、Equipment 的相关绝对制造时间保持一致平移，数值、持续时间、规格、修饰和告警算法不变。
- 同一代码可由不同部署配置分别提供客户显示日期和内部真实日期服务。

## Acceptance criteria

- [ ] `data_forward` 缺失或关闭时，查询参数、返回时间及现有测试行为不变；开启时非负整数偏移被统一应用，非法配置给出明确错误。
- [ ] 源时间 `2026-08-29 10:30` 在四天策略下显示为 `2026-09-02 10:30`，输入 DataFrame 不被原地修改，重复读取原始快照不会累加偏移。
- [ ] 直接查询型仓储把显示窗口反向平移后查询，并把 Q-Time `timekey`、IJP `print_time/day` 平移回显示窗口；区间开闭语义保持不变。
- [ ] Yield 的 `warehousing_time/array_input_time`、共享 Inline 与 AOI_RS 的 `start_time`、Equipment 的 `glass_start_time` 均使用同一策略；非时间字段不变。
- [ ] 截止日为 `2026-09-02` 时三个月全量快照起点为 `2026-06-01`；截止日跨到 `2026-10-01` 时起点为 `2026-07-01`。
- [ ] 原始 Parquet 中保存源时间；显示截止日之后的平移记录不会进入页面或下载结果；数据库失败和陈旧快照降级语义不回归。
- [ ] 设备三天新鲜度按源时间判定，再平移合格结果；真实与仿造事实采用相同显示策略。
- [ ] 派生缓存能区分开关和偏移量；切换策略不会复用另一模式的缓存结果。
- [ ] 新增单元/集成测试覆盖关闭、开启、跨月、窗口边界、空表和重复读取；相关关键页面 E2E 与既有回归测试通过。

## Out of scope

**Category:** enhancement  
**Summary:** 为所有报表制造事实建立可配置、可逆的源时间到显示时间平移契约，默认偏移四天，并保持原始快照与既有算法不变。

**Current behavior:**

- 各域独立读取制造事实时间，没有共享策略或缓存签名。
- 产品快照窗口以“三个月前同日”为起点，直接查询窗口没有显示时间到源时间的换算。
- Equipment 的真实数据新鲜度和仿造回退依赖真实 `glass_start_time`。

**Required behavior:**

- 全局配置产生一个不可变的日期前推策略；配置缺失/关闭为零偏移，开启时校验非负整数天数，并提供稳定签名。
- 仓储边界把页面显示窗口换算为源窗口，把返回的绝对制造时间统一平移，再按显示窗口过滤；输入对象和原始 Parquet 不被改写。
- 快照型数据源从截止日往前第三个月的月初加载原始事实；到新月份后的成功刷新淘汰更早源事实，增量、去重、原子写入和降级语义保留。
- IJP 明细与日聚合、Q-Time 明细、Yield 相关绝对时间、Inline/AOI_RS、Equipment 真实与仿造事实保持域内一致。
- 派生缓存签名包含策略签名，使客户模式与真实日期模式相互隔离。

**Key interfaces:**

- 全局 `data_forward` 配置：`enabled: bool`、`offset_days: non-negative int`。
- 不可变日期前推策略：提供有效偏移、稳定签名、时间窗口反向换算及 DataFrame 时间列复制平移能力。
- 各仓储现有公共查询签名保持兼容；调用方继续传显示窗口。

**Edge cases:**

- 配置缺失、关闭、零偏移、非法 bool/天数；空表、缺列、无效时间；月初、跨年和闰日。
- 原始快照含平移后晚于显示截止日的记录；陈旧快照回退；同一快照重复读取及运行时切换策略。
- 半开 Q-Time 区间和闭区间 IJP/日窗口保持既有边界；Equipment 源时间新鲜度不受显示偏移干扰。

**Verification expectations:**

- 单元测试固定时钟验证策略、窗口和每域列映射；集成测试验证快照原始时间、过滤、降级及缓存隔离。
- E2E 验证至少一个快照型页面和一个直接查询型页面显示四天平移后的日期，并回归关闭模式。
- 执行仓库现有 Yield、Inline、Indicator、Equipment 定向测试和 smoke；测试产物放在 `output/test-results/` 或 `output/tmp/`。

**Out of scope:**

- 不改变质量算法、修饰结果、日志/TTL/审计时钟、数据库单例或生产部署端口。
- 不复制业务源码，不把显示时间持久化进原始事实快照，不迁移历史 Parquet。
