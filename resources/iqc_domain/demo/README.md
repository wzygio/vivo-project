# IQC 展示数据

- `inspection.json`：`IQC来料检验特性数据明细报表 (1).xlsx` 的 `sheet2`，128 行、25 列。
- `lifetime.json`：`寿命测试报表 (自动保存的).xlsx` 的 `Sheet1 `（名称末尾有空格），12 行、20 列。

数据通过本机 Excel 读取工作表可见值后提取，仅用于用户指定的假数据展示。
保留原始列顺序、数值和空白；移除来料表末尾的空行。Excel 日期按工作表时钟保存，
不进行时区换算或日期前推。寿命表首行的“屏体/模组”“量产/新品”也是源表内容，按原样展示。

页面运行时只读取这些 JSON，不打开加密 Excel、不连接数据库、不重新生成随机数据。
源工作簿修改后需重新提取；页面不会自动同步。CSV 下载保留原始数值（如 0.9752），
网页按原表格式将衰减比例显示为 97.52%。
