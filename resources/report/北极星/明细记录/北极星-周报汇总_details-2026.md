## 第6页：SPC特性管理 - IJP异常调差

- 原因：IJP日常值班监控时，发现打印时间增加（每日DMU监控禁用nozzle数量累积过多）,导致TT增加，按照标准处置流程进行冲墨解禁孔，喷检无异常，同步点放加检确认产品无异常；IJP膜厚是通过量测TEG表征，TEG大小相比AA区更小，解禁nozzle之后个别nozzle的体积角度的变化使得在TEG上表现的更明显，IJP膜厚离散性有变化

### LL1 破片复机流程改善
- 改善对象：真空转换腔室出现粉碎性玻璃破片后的开腔复机流程。
- 改善前流程：设备基板状态确认 → 粉碎性破片 → 开腔清洁（按清洁流程进行） → MQC + 点放2 half → 确认加检结果 → 复机生产。
- 改善后流程：设备基板状态确认 → 粉碎性破片 → 开腔清洁（按清洁流程进行） → 设备腔室Cycle Purge 10次 → 开腔清洁（按清洁流程进行） → 设备腔室Cycle Purge 30次 → 点放2 half → 确认加检结果 → 复机生产。
- 清洁流程：①人工用手拾出大面积碎片；②吸尘器进行大面积碎渣清洁；③高压气枪进行碎屑吹扫出腔室外；④对设备管道、Cover缝隙、设备腔室机构夹层进行气枪吹扫和擦拭；⑤用酒精无尘布进行平台、Pin、Clamp机构确认和清洁Particle擦拭；⑥强光灯照射，查找有无残留Particle。
- 结论：开腔复机后未发生异常，进行流程改善。
