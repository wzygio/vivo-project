厂别，备件类型，设备类型，膜层，制程，寿命规格，站点，机台号-腔室，测量值，测量时间，使用进度，预警状态
1. 颗粒度层级从大到小依次为：
    - 厂别
    - 备件类型，设备类型
    - 膜层，制程，寿命规格
    - 站点，机台号-腔室，测量值，测量时间，使用进度，预警状态

2. 数据来源：
    - 厂别，备件类型，设备类型，膜层，制程，寿命规格：规格表
    - 站点，机台号-腔室，参数名称，测量值，测量时间：数据表。
        * 使用“规格表”中的“站点，机台号-腔室，参数名称”三个字段去匹配数据表来进行查询
    - 使用进度，预警状态：自行计算
        * 使用进度：$ 使用进度（百分数） = 测量值/寿命规格 $
        * 预警状态：如果“使用进度＞90%”则显示“预警”，如果“使用进度＞100%”则显示“超规”，否则显示正常

将“规格表”中的数据转化为目标格式。想要将“规格表”中的字段转化为目标格式，您需要重点解析以下两个字段：
1. 站点：每条记录应该只对应一个站点，您需要通过换行符将其截断，
    - Example
    ```
    1K500
    12500
    13500
    B9500
    ```
2. 机台号-腔室：
    - 拆分步骤：
        * 首先，通过换行符拆分组别
        * 然后，通过“ ”（空格）或“-”拆分机台号和腔室
        * 再然后，通过“/”拆分多个“机台号”或“腔室号”
    - Example
    ```
    3AFS03/04/05/11 PM4/PM5
    ```

    上述字符其实对应着8个组合分别是：
    ```
    3AFS03-PM4
    3AFS03-PM5
    3AFS04-PM4
    3AFS04-PM5
    3AFS05-PM4
    3AFS05-PM5
    3AFS11-PM4
    3AFS11-PM5
    ```
