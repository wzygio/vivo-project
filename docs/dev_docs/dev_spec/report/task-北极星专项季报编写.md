        - 行字段：排序为“总不良-各Defect Group不良率-各Defect Code不良率”
- 计算逻辑：
    - 程序入口：`src\yield_domain\core\mwd_trend\mwd_trend_processor.py`
    - 快照：构建储存历史数据的L1快照，避免已经计算过的历史数据反复计算。采用本地Excel表的形式即可。
