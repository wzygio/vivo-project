# Task：报表显示数据日期前推
- 身份背景：我是一家OLED显示屏制造公司的大数据分析工程师
- 项目背景：我们正在开发的是一款面向客户的企业级报表，但需要预留时间来修饰数据
- 任务目标：请帮助我开发一项数据前推的功能，即页面上显示的数据虽然看起来是当天的，但其实4天之前的

## Design
我的初步设想如下，对于各domain：
1. repository层将提取的明细数据中的时间字段加4天。后续所有处理逻辑不变。
2. data_loader改为提取三个月之前的第一天到当日，比如今天是9月2日，则提取从6月1日到今天的数据生成本地快照：
    - 此前提取的是三个整月，比如今天是9月2日，提取的是6月4日到今天的数据
    - 相应的快照的更新逻辑也可以改动，比如到了新月份就将最早的一个月份删除（增量更新的逻辑不变）
3. 我们内部人员可能还需要查看真实日期的数据：我打算复制一下项目，使用另一个端口开启一个新服务，避免二者冲突。

当前项目domain包括：
- `src\equipment_domain`
- `src\indicator_domain`
- `src\yield_domain`
- `src\inline_domain`

是否前推4天则通过一个flag来统一控制：`config\global.yaml`
