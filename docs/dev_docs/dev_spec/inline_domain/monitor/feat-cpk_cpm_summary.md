### Data Source
- 历史汇总表：`resources\inline_domain\monitor\北极星报警率与CPK汇总.xlsx`，该表格中sheet页分为三种类型：
    - CPK汇总表：“{产品型号} CPK”，关键字段如下

## Requirements

### 数据统计逻辑：
1. 关键字段填写逻辑：
    - CPK总项目：复用“当前报表统计逻辑”
    - 预警项目数：历史预警表中，“flag=False”（不进行修饰，释放真实数据）的记录数
    - 达标项目数：CPK总项目 - 预警项目数
    - CPK≥1.33达标率：达标项目数/CPK总项目（如果CPK总项目为0，则达标率设为1而不是0）
2. 向上汇总逻辑：不同“周期类型”的“时间标签”之间的对应关系如下
    - 由“季度”汇总为“年度”：加和即可
    - 由“月度”汇总为“季度”：常规逻辑，每三个月对应一个“季度”
    - 由“周度”汇总为“月度”：当前周度根据“ISO周”划分，请问ISO是否有相应规范，如果没有就采用“向后归属”的模式
        - 比如，一个周度跨越两个月，那么就将其归属于后一个月份。因为归属于前一个月份的话，有时当周数据还没有完全产出，不应该纳入统计
