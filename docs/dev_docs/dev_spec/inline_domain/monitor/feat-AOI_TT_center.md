# Task：AOI_RS监控看板
请在下面这个程序中，帮我新增一个“AOI_RS监控看板”模块：`app\pages\超规预警看板.py`

## Requirements
- 目标样式：`docs\project_files\inline_domain\monitor\AOI_RS-趋势图-季报模板.xlsx `，其中为每个“产品-厂别-站点-RSCode”的“年度-季度-月度-周度”的RS density做成的数据表
- 筛选条件：
    - 厂别-单选（默认Array）
    - 产品-可多选（默认全选），后续产出表格时，按照“产品型号”分为不同的Sheet页
    - 站点-可多选（默认全选）
    - RSCode-可多选（默认全选）
    - 年度-分为上下半年，可多选（默认截止到当前时间）
    - 季度-可多选（默认截止到当前时间）
    - 月度数-可多选（默认截止到当前时间）
    - 周度数-数字（默认为5）
- 计算逻辑：请参考`app\pages\AOI_RS监控报表.py`，但有以下不同
    - 时间尺度：与我们要做的看板不通，该报表固定为计算两月三周七天
    - 快照：L1快照不需要明细快照，但是储存本地数据表储存历史数据，避免已经计算过的历史数据反复计算。
    - 快照更新：仅对当前可能影响到的时间周期进行更新，更新逻辑可参考`app\pages\超规预警看板.py`中的“异常片预警看板”模块或“CPK预警看板”模块
- 展示样式：只需展示表格（st.dataframe即可），不需要绘制图像
