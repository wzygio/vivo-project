- 来源为用户提供的企业加密 Excel；工作表依次为 Z576-detail、Z576-summary、Sheet3、Sheet2。
- detail 有 936 行、41 列，STEP_ID=1B455、PARAM_NAME=CD1、TARGET=12.73。
- 6 张大板：L3Z86902B01/15/30、L3Z86902901/15/30；每张 SITE_NAME=1…156。

- 调整前包含 L3Z86901L01/15/30、L3Z86901N01/15/30；调整后和修正后使用 detail 中的 6 张大板。
- 每条汇总列为 ID、膜位、MAX、MIN、AVE、STD、Δ/（MAX-MIN)。标题和空行不能作为记录；ID 需在各块内补全。

## 结论与边界

首张明细无法重算全部三阶段汇总，也没有显式膜位映射。报表应读取 summary 已有值，保留业务分类，不推断缺失来源或计算公式。
产品由工作表配对标识确定，PRODUCT_SPEC 是规格名称，不能当作 Z576 产品代码。
企业客户端会重新加密磁盘上的 XLSX 转换输出；解析必须在转换后立即完成，不能依赖跨进程明文临时文件。
fr_file_decryption 的 excel-values 策略可读出全部数据，但退出时可能在代理释放前卸载 COM apartment。调用方建立外层 COM 生命周期，使嵌套调用返回并释放代理后再卸载。生产隔离临时副本、立即读取转换字节，结束清理。共享单表 reader 会在标准 pandas 路径为重复表头增加后缀，不适用于该多块汇总的原始布局，因此未采用。标准工作簿直接按 header=None 读取。分析过程未连接数据库。
