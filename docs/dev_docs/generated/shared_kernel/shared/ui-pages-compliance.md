## 自动化与浏览器证据

- 大范围回归：`tests/unit/app`、`tests/architecture`、备件、Yield Plotly key、Yield 预警策略及 CPK 看板测试，**823 项通过**。
- 最后补充的 SPC 上传、工作簿缓存身份、CPK/CPM 查询签名和 Yield 上传失效测试组：**29 项通过**。与上述回归有重叠，不相加。
- 浏览器隔离验收：CTQ、AOI_RS、AOI_TT、BySheet、ByLot、备件、IQC 蒸镀、超规看板、资料上传、寿命、密集点及 IJP 共 **12 个场景通过**。局部事件保持外层加载/发布计数，显式整页重跑作为正向对照可推进计数。IJP 场景还验证 AA→孔区会重新装配正确服务，此后筛选与查询继续局部执行。
- 实际图表滚动验收：SPC、CTQ、AOI_RS、AOI_TT 共 **4 个场景通过**，各 18 张图。普通及预警图各槽位的原生滚轮可上下浏览主容器，坐标范围不变；工具栏放大/重置可用；560px 窄屏没有页面横向溢出。SPC 使用实际页面滚动布局，其余使用原生布局。上述浏览器合计 **16 个场景**。
- 源码语法及图表入口检查：`app` 下 155 个 Python 文件解析成功；26 个 `st.plotly_chart` 调用均有显式配置。配置检查本身不作为滚动实测证明。
- 独立代码复核未发现新的高、中风险问题。`git diff --check` 通过；路由检查覆盖规范、CONTEXT、知识索引及迁移后的引用。

可复用的浏览器入口为 [页面交互脚本](../../../../../tests/e2e/ui_pages_compliance.js)、[补充报表隔离脚本](../../../../../tests/e2e/report_fragments_isolation.js)、[图表滚动脚本](../../../../../tests/e2e/inline_scroll_compliance.js) 及 `tests/e2e/fixtures/` 中相应的无数据库夹具。本轮执行日志、计数、截图、进程身份及清理结果保存在 `output/tmp/ui_pages_audit/`，按临时验证产物生命周期管理。

大回归还发现并修正两类过时测试：QTime 已明确不展示查询提示，因此断言其策略签名变化、旧图持续失效和重新提交；Yield 趋势预警已只按周度判定，因此正向夹具改为周度，并新增“仅月度 spike 不预警”断言。没有为通过测试改变这些生产规则。

## 文档合并与验收边界

原三份滚动、多模块 fragment、SPC 重复加载说明已删除。独有机制和历史证据边界已合并到统一规范，旧链接及资源注册已清理；CONTEXT 和 `references/index.md` 继续直接路由到统一规范。

本轮使用内存数据和隔离适配器验证交互，没有连接正式数据库或通过上传操作写入维护工作簿，没有重启正式服务。所有本轮浏览器夹具服务及其子进程已按记录身份清理，并确认对应监听释放。

代码审计覆盖全部 17 个入口；隔离浏览器计数不等于全部正式数据、全部图表数量和用户原标签页的现场验收。现有页面的业务例外、源更新路径和受限错误提示均保留，后续修改须按统一规范针对变化分支补验证。
