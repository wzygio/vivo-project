## 修正与验证

- `TREND_CHARACTERISTICS` 固定四项清单；在生成物料展开区之前筛选有效测点。没有对应测点的物料不生成展开区；首个有测点的物料默认展开。更换展开区状态键，避免沿用此前默认折叠的状态。
- 查询没有可绘制测点时仅显示整体提示；完整检验明细保留全部查询行。
- 回归测试先复现“首个物料无测点、后续 DSC-Tg中点有数据，但初始图表数为零”，修正后立即出现图表。另验证固定清单、无有效测点时无物料展开区、单侧缺测、规格、加载交互和普通模式字段边界。
- 执行相关图表单元测试、IQC 查询与预警 AppTest、业务规则和缓存测试，共 42 项通过。真实数据图表构建验证与浏览器交互测试相互独立；浏览器使用不连接数据库的合成数据，模拟 34 个空物料排在前面，验证四项图表立即显示、空物料省略、其余物料按需展开以及无测点／空／失败状态，在 1365px 和 768px 宽度下均通过。截图已检查，测试记录的 18 个进程均已结束，8523 端口及测试进程所属监听均已释放。

可重建的数据库核查汇总、浏览器截图及进程清理记录位于 `output/test-results/iqc_evaporation_trends/`；不包含凭证或连接信息。该核查是指定窗口的证据，不表示其他窗口或产品选择必然具有相同记录数。
