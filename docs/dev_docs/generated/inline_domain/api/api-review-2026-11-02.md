## Standards

发现1项P2硬性问题：公共服务接受空DataFrame时先返回零记录，没有先检查有效Flag证据；Inline既有reader空表又跳过schema验证，因此损坏表头可能得到成功零异常。违反来源错误不得伪装为零异常的契约。

关闭：新增API专用strict_empty验证，保留旧页面默认行为；API组合强制启用，RS额外要求chart_kind；服务在空结果前检查Flag。真实OOS/OOC工作簿对照覆盖空白、缺Flag、缺身份列和合法空表。独立评审者复核确认关闭，无剩余具体阻断项。

未发现充分证据支持的严重／高危鉴权、授权、公开政策、游标、持久化或错误泄露问题。Office强制取消限制、逐行元数据准备成本保留为已说明的运行风险，未虚构已做正式账号验证。

## Spec

独立发现1项同根因P2：无schema空表被误报成功零异常，与缺schema／释放证据应503相违。新增缺Flag集成测试原先只覆盖非空，公共服务空表测试也使用了无表头夹具。

关闭：严格验证及真实空表对照测试落地；有效空表夹具具有真实表头，另增无schema失败断言。复核确认本轴全部具体发现关闭，无新增阻断项。

其余核验：四Inline OOS/OOC、RS真实粒度、Q-Time起点、Yield厂别必需／站点可空、持久人工释放、只读本地、字典维护、公开政策、授权与分页均有相应实现及隔离测试。
