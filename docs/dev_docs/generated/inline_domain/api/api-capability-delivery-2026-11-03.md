## 功能与契约

现有路径新增 `event_type=CPK/CPM`，沿用 SPC 授权，默认事件仍为 OOS。能力记录保留必要六列，使用 `capability` 对象与稳定公开键编号，在原有十一列之外增加指标值、下限和完整 ISO 周信息；旧片／Lot JSON 形状保持不变。查询只读已维护台账，复用 False、严格 `<1.33`、实际数据跨度与周期排除规则，不运行分析或维护汇总。

默认取上周；自定义日期仅选完整包含且已结束的 ISO 周。没有相应周期资料保留来源不可用语义。明确工作簿版本变化时完整重读来源一次，重新检查政策；持续变化与其它不可用情况仍明确失败，不绕过缓存校验或请求超时。

调用程序支持新事件，CSV 统一十七列，JSON 保留完整响应；自动取完所有显式分页，下载不按预览二十行或每页五百行截断。部分成功有按钮、文件名和伴随元数据标记。
