# 配置化 PPA 截断线并使用点位数据绘制周期箱线图

Related: `config/spc_config.yaml`、CPM/CPK 监控报表、自动预警看板共享的数据修饰链路

## Current context

- Sheet 超规数据修饰目前以每项参数的正式 `lsl` / `usl` 为截断边界，所有参数采用同一规则。
- CPM 月、周、日周期箱线图目前以每片 Sheet 的 `sheet_mean` 为样本，因此不能呈现周期内所有测试点位的真实分布。
- 周期能力指数的 sigma 数据源已有独立配置入口，但周期箱线图的数据源尚不可配置。
- 数据修饰发生在共享后端，CPM/CPK 监控报表与自动预警看板会消费同一份修饰后数据。

## Desired outcome

- `param_name` 包含 `PPA` 的参数按可配置的扩展截断线修饰：下边界为 `lsl - 0.5`，上边界为 `usl + 0.5`；其他参数保持现有规格线规则。
- 月、周、日箱线图可配置为使用相应周期内全部 `param_value` 点位，而不是 `sheet_mean`。
- 两项配置均由 `config/spc_config.yaml` 提供，并具有兼容旧配置或无效配置的安全默认值。

## Acceptance criteria

- [x] 当参数名包含 `PPA` 时，位于正式规格线之外但仍在扩展截断线以内的点位保留原值；超出扩展截断线的点位被确定性地修饰到扩展边界以内。
- [x] 参数名匹配不区分大小写；未匹配 `PPA` 的参数继续使用正式 `lsl` / `usl` 作为截断边界。
- [x] PPA 匹配文本和上下边界偏移量可在 `config/spc_config.yaml` 中配置。
- [x] 周期箱线图配置为点位模式时，每个月、周、日箱体使用该周期内全部有效 `param_value`；图表不再以 `sheet_mean` 作为箱体样本。
- [x] 周期箱线图数据源可以在 `config/spc_config.yaml` 中切换，并在配置缺失或取值无效时安全回退到点位模式。
- [x] USL、LSL、UCL、LCL 参考线仍来自 Sheet 特征/规格数据，周期轴范围和顺序保持现有行为。
- [x] 现有 flag=false 的“不修饰”语义保持不变；CPM/CPK 指数 sigma 数据源配置不受影响。
- [x] 新增行为有自动化回归测试覆盖，相关既有测试保持通过。

## Agent Brief

### Current behavior

- 修饰链路先按正式规格识别超规 Sheet，再根据用户 flag 对该 Sheet 的越界点位做确定性截断；截断边界固定为正式 `lsl` / `usl`。
- 周期箱线图从 Sheet 特征构造月、周、日样本，同一 Sheet 在三个相应周期各贡献一个 `sheet_mean`。
- 周期能力指数的 sigma 来源可独立选择 Sheet 均值或点位值，该设置不控制箱线图。

### Required behavior

- 修饰链路接受从 SPC 配置解析出的名称包含规则和边界偏移。匹配参数的有效截断下界为 `lsl + lower_offset`，有效截断上界为 `usl + upper_offset`；默认 PPA 规则为 `lower_offset=-0.5`、`upper_offset=0.5`。
- 正式 OOS 判定、正式规格字段和用户 flag 均不改变。扩展规格区间只决定已启用修饰的点位是否需要截断，以及截断后落入哪个边界以内。
- 周期箱线图的数据源具有独立配置。点位模式下以测量时间和 `param_value` 构造月、周、日样本；Sheet 均值模式保留为兼容选项。
- 周期能力指数仍使用原有独立配置，不能被箱线图数据源设置隐式改变。

### Interfaces and data contracts

- 配置加载器提供规范化后的周期箱线图数据源，以及数据修饰截断规则。调用方只消费已验证的值，不直接解析 YAML。
- 核心修饰逻辑接收纯数据规则，不自行读取文件；未提供有效规则时保持非 PPA 参数的既有行为。
- 周期图表构造接口同时接收 Sheet 特征与原始点位数据。周期轴和规格参考线继续以 Sheet 特征为依据，箱体样本按已解析的数据源选择。
- 点位时间优先使用测量记录的 `sheet_start_time`，无效时间或无效 `param_value` 不进入箱体。

### Edge cases

- 参数名大小写差异、空值、缺少规则、未知箱线图数据源、单边规格缺失和空数据均需安全处理。
- flag=false 的 Sheet 原始值必须完整保留。
- 已启用修饰但仅超出正式规格、未超出 PPA 扩展边界的点位必须保留。
- 月、周、日均需使用相同的点位样本语义，并保持现有可用周期裁剪与排序。

### Verification

- 以公开函数行为分别覆盖 PPA 扩展边界、非匹配参数兼容行为、flag=false，以及配置解析默认值/无效值。
- 以图表构造结果覆盖点位模式包含全部测量值、Sheet 均值兼容模式、周期分类和规格参考线。
- 运行相关单元测试后再运行项目测试集，确认共享后端与现有页面行为无回归。
