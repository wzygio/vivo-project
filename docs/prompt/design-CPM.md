# CPM监控报表

## Background
你好，我是一家OLED制造厂的员工，该项目是一个用于给客户展示厂内数据的报表。
现在需要开发一个SPC的CPM监控报表。

## Terms
0. LOT/SHEET/GLASS/PANEL：
    - Lot：生产单元，一般一个lot包含30个sheet。ID为9位。
    - Sheet：显示屏在前段工艺中是一整个大板，我们称之为Sheet。ID为11位，前9位为Lot ID。
    - Glass：Sheet在蒸镀工艺段被一切为二。ID为12位，前11为Sheet ID。
    - Panel：在屏体段（最后一道工艺）大板才会被切割成手机尺寸的大小，切割后的屏体我们称之为Panel。ID为15位，前11为SheetID，后四位为坐标。
1. Mapping：将每一个Panel根据位置坐标拼接成一整个大板来寻找前端工艺的问题，是一种异常调查的常见手段。而拼接成的大板就叫做Mapping。注意，这里的拼接是在数据维度上，因此可以根据需求拼接。
    - 膜位：Mapping图上Panel所在的位置就叫做膜位。比如我们可以将所有的panel拼接成Mapping图，来观察哪个膜位的不良较为显著。
2. Defect Code：不良代码
3. SPC：统计过程控制。对于我们公司来说，具体形式为：
    - 针对每个监控指标，在一个sheet上的多个点位进行测量，取均值作为该sheet的测量值。
    - 每个指标都有上下限，通过“自动预警报表”进行监控。
    - 指标为“站点-参数”的组合：每个站点可能会测多个参数，但每个参数可能会在多个站点测量，所以只有组合才能锁定唯一一个监控指标

## Workflow
现在，我们需要统计每个Lot在每个监控指标上的CPM，大致步骤如下：
针对每个SPC监控指标
1. 每个计算出每个sheet的测量值（spc_domain已经实现）
2. 计算每个LOT的CPM（CPM的计算公式您查询一下即可得到）
    - lot与sheet的之间归属关系为：Sheet ID的前9位为其所属的lot ID
3. 绘制Lot别趋势推移图（可参考“入库不良率分析看板”中的lot趋势图）

## Requirements
1. Backend：请在spc_domain中来编写后端程序，其中逻辑您可以复用
    - 请注意，我们只针对SPC指标计算CPM。不包括AOI和CTQ。
2. Frontend：新建页面要求如下
    - 筛选框：产品型号，厂别，参数名称，站点
        * 产品型号：参考自动预警看板
        * 厂别：仅包含ARRAY/OLED/TP
        * 参数名称：提供全选按钮，默认为空。
        * 站点：提供全选按钮，默认为空。跟随“参数名称”联动，即选择“参数名称”后，“站点”筛选框下仅

    - 每个监控指标放入一个Expander中，默认展开。增添全部展开/折叠的按钮。
    - 点击lot可查看该lot下所有sheet的测量值（联动关系可参考“入库不良率分析看板”中的lot趋势图）
