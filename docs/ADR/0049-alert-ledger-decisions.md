# ADR-0049 预警台账保留人工决定

已采纳，2026-11-24。适用于有独立预警来源的报表、自动预警看板和既有异常 API。

## 背景

每日巡检需要重算当前预警，管理员则需要对同一条记录作出跨巡检有效的决定。此前部分生产者整表覆盖发布结果，另一些只保存布尔开关，达标或缺测可能让人工决定随候选一起消失。

## 决定

各子域在已注册的本地工作簿中按稳定业务键保存决定。新键采用本域默认值。再次计算只更新生成字段，保留 Flag 和人工替换值。当前已达标或无法判定的记录保留决定，重新超规时再次使用。记录的身份与当前测量值独立。

预警中心在 `?admin=ture` 和 `?admin=true` 下提供维护。False 放行符合当前发布条件的原值，True 应用本域修饰，Delete 隐去公开记录。矩阵与 HTTP 在行级决定之外共用指标 × 产品显示台账。维护产生的版本变化要传递到公开读取；编辑决定不能改变事实的发生时间或来源新鲜度。

仅有独立预警事项的报表提供维护。Yield 上游指定良损、Sheet 不良率覆写和 Mapping 热点剧本沿用既有数值算法。HTTP 继续从本地发布数据取数，通知沿用该接口。

## 取舍与后果

逐次覆盖整张台账无法恢复历史人工决定；全域共用一个按行号维护的文件又会把不同子域的业务键、锁和发布时间绑定起来。因此保留子域工作簿，并允许决定表与当次发布表同簿提交。旧版纯发布快照只能提供当时保存的候选。寿命台账的旧排序编号无法证明原样品身份，迁移时保留旧编号及决定为未判定，并为后续可识别的样品登记稳定匿名编号。管理员需复核这些新编号。
