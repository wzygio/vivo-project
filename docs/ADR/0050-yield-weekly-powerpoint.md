# ADR-0050 良率周报复用已发布预警与 Group 看板图表

已采纳，2026-11-24。

## 背景

良率周报需要总结上一完整 ISO 周，并附上看板当前的 Group 月周天趋势。已发布的预警工作簿同时保留当前状态和历史周记录，人工放行决定可以独立更新。用户模板带有固定封面、双产品正文和用于说明的样例页。

## 决定

共享发布读取器验证来源与发布有效性。Yield 周报应用按目标周从已发布数据提取趋势与 Lot 记录，读取明确放行的决定，并输出客户可读结论。页面与离线命令复用同一生成器。正文图片从与看板共享的 Group 图表构建函数批量导出，套用模板窗格排版。

## 取舍与影响

- 实时预警中心按当前记录筛选。周报按指定历史周筛选，即使本周替代了当前标记也可看到上周的记录。独立重新分析会产生额外取数，并可能引入与人工放行不同的结论。
- 直接导出 Plotly 图像保留看板数据和比例，生成不依赖网页状态。PPT 的图像是静态的，标题和结论使用模板的可编辑文本。Chrome 或 Chromium 提供静态渲染，受保护模板继续使用本机 PowerPoint 读取。
- 缺少产品记录可如实呈现数据状态，损坏或覆盖不足会阻断生成。输出只在所有产品组成完整演示文稿后提供。
