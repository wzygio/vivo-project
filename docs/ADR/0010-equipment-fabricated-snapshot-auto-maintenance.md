# ADR-0010：关键备件仿造快照自动维护

- Status: Accepted
- Date: 2026-08-12
- Scope: `equipment_domain` 仿造当前值的生成、TTL 刷新和日推进
- Supersedes in part: ADR-0003 第 2、3、6 点

## Context

ADR-0003 将仿造快照的首次生成和后续更新限定为显式运维命令。Task2-1 要求报表无需人工触发即可保持仿造数据有效，同时要求测量值随时间连续推进，不能在每次更新时重新随机抽样。

## Decision

1. 应用服务缓存每小时重新进入快照层；仿造快照仍以自身 24 小时 TTL 决定是否发生有效更新。
2. 当前规格签名对应的仿造快照缺失时，快照层自动生成初始数据；有效时直接读取；过期时自动更新。
3. 文件跨过多个完整 TTL 周期时，一次补齐相同数量的日推进。每个周期把测量时间增加一天。
4. 测量值以配置增量为中心执行小幅、确定性的日变化。变化由稳定业务键和目标日期派生，不调用运行时随机数。
5. 测量值达到寿命规格后按周期回绕，保留超出规格的部分作为更换后新备件的起点，并限制在配置重置区间内。
6. 自动更新通过临时 Parquet 原子替换写回，保持键集合、行数以及真实/仿造快照隔离不变。
7. 原有生成和更新命令继续保留，作为诊断、测试和人工维护入口；它们不再是报表获得有效仿造数据的前置条件。

## Consequences

- 页面正常访问即可自动补建和推进仿造数据，不再依赖人工定时执行命令。
- 同一输入状态的下一步结果可复现，且相邻日进度保持接近配置增量。
- 长时间未访问后会一次追赶多个周期；这比只推进一天更符合测量时间与快照年龄的一致性。
- 报表读取现在可能写入 `data/equipment`，因此自动维护错误会明确上抛，不以空数据静默掩盖。

## Verification

- 单元测试覆盖：缺失自动生成、有效快照跳过、过期推进、多周期追赶、确定性微扰、越线回绕、结构与键校验。
- 集成与 equipment smoke 继续验证真实数据优先和仿造数据补缺。
