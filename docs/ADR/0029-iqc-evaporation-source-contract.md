# ADR-0029：IQC 蒸镀材料报告保留目录与存储结论的来源边界

- Date: 2026-09-15
- Status: Accepted
- Scope: IQC 蒸镀材料报告
- Trace: [需求与数据源分析](../dev_docs/dev_spec/iqc_domain/datasource-蒸镀材料报表分析.md)、`.scratch/iqc-evaporation/PRD.md`

## Context

蒸镀材料页面从本地示例迁移至用户提供的 WMS SQL。SQL 先按目录展开特性，再关联票据的测点及存储结果。
目录曾因缺少 SELECT 权限而不可读，而测量结果表已经可读；直接用测量结果表替代目录会遗漏未录入项目。
SQL 同时输出整体 IQC/COA 结果和测点 CASE 判定，二者不能互换，尤其是 CASE 会把 NULL 落入 OK 分支。

## Decision

1. 仓储复用共享 DatabaseManager，在只读事务执行绑定日期参数的查询，完整保留目录展开及结果 LEFT JOIN。
   缺表、权限或查询错误使整次读取失败，不以部分记录、示例数据或空集作为成功结果。
2. IQC_RESULT、COA_RESULT 原值是报表结论，缺失保持空白；规格/测点用于展示，不在本次读取中重新判定。
3. application 持有读端口，composition 绑定 infrastructure；core 维护公开字段投影及筛选。
   蒸镀材料实现在各层的 `eva_materials/` 子模块中，对应 section 也使用同名子模块；域级 composition 保持统一组装。
   既有寿命示例继续独立读取，生产页面不依赖其数据。后续业务的组织规则见 [CONTEXT.md](../../CONTEXT.md#business-submodule-organization)。
4. 检验日期窗口遵循原 SQL 的 CHECKEDDATE；仓储反算源窗口，输出 REQUESTDATE/CHECKEDDATE 时应用共享前推与当日截止。
   Streamlit 仅缓存公开 DataFrame，键包含显示窗口、前推策略、截止策略和所选产品，TTL 服从全局配置。
5. 页面仅接收所需 27 列，保留原表样式并分页；数据库内部字段和异常细节不送往普通用户界面。
6. 2026-09-15 根据用户后续要求，infrastructure 固定限定工厂 V3、物料分类有机。
   页面仅保留同一行的日期和产品型号；型号选项服从全局 enabled_products，原项目名列改名产品型号。
   实库复核当前范围 591 行均为通用后，用户最新要求将“通用”作为独立合法选项追加并去重；不修改全局配置。
   所选型号仍按源值精确匹配，不将通用材料自动归属到任一启用产品。

## Alternatives Considered

- **只读测量表**：减少依赖，但丢失尚未测量的目录项目，因此不采用。目录权限最终由用户开通。
- **根据测点重算整体 IQC/COA 结果**：可得到非空结论，但未获业务计算口径且与源存储结论不同，因此不采用。
- **故障回退本地示例**：能显示表格，但无法代表当前来料事实，因此不采用。
- **页面直接 SQL**：接入短，但难以隔离时间转换、查询故障和 UI 测试，因此使用应用端口。

## Consequences

正面：可追溯至原 SQL，未测项目不丢失，缺失结论不会被表述成合格；可用固定端口测试异常路径。
代价：依赖目录权限及完整数据库链路；结果录入前会显示空白。目录的多个备注可能匹配同一特性，保留原 SQL 行数语义。
约束：若未来需要归并目录重复、计算整体结果或再次调整物料/产品范围，须先定义新的业务口径，不能当作展示优化改变事实。

## Verification

以下为首版验证；当前产品筛选收敛验证见所链接数据源文档的“产品筛选收敛验收”。

- 真实数据库：原 FineReport SQL 与实现的 2,518 条记录、26 个业务字段逐行多重集对账通过。
- 29 项聚焦测试通过，涵盖字段/空白/筛选、只读查询窗口与截止、缓存热重载、失败重试、SQL 关联、架构和原示例回归。
- Playwright 真实页面：查询、分页、分类及特性筛选、27 列、空集、1365px/768px 无页面横向溢出通过。
- Playwright 受控端口：故障与恢复、末页 201–205 行、存储 NG、空白 COA、筛选空交集通过。
- 浏览器证据位于 `output/test-results/iqc-evaporation/`；测试入口在数据源分析中列出。
