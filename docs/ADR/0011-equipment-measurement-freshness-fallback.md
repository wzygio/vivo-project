# ADR-0011：关键备件真实测量新鲜度与仿造补位

- Status: Accepted
- Date: 2026-08-12
- Scope: `equipment_domain` 当前值报表的真实/仿造来源选择
- Supersedes in part: ADR-0003 第 4 点

## Context

真实快照保留 90 天查询窗口，但报表验收要求每个备件类型都有数据，且最终测量时间位于近三天内。若不考虑时间地无条件优先真实记录，陈旧真实值会覆盖新鲜仿造值，使报表违反当前性约束。

## Decision

1. 数据库仍按 90 天窗口抓取并保存真实快照，便于查询和诊断。
2. 进入报表匹配前，真实记录按配置的 `query.measurement_max_age_days` 过滤，当前为三天。
3. 新鲜真实记录继续优先；真实记录缺失或陈旧时，才使用当前规格签名的仿造快照补位。
4. 未来时间、无法解析的时间和窗口外时间均不参与真实优先匹配。
5. 仿造快照仍遵守 ADR-0010 的自动生成、TTL 推进和时间约束。

## Consequences

- 报表展示值同时满足真实优先和三天新鲜度要求。
- 真实快照没有被裁剪或覆盖，只有报表匹配视图执行新鲜度过滤。
- 陈旧真实记录会暂时由仿造值替代；待数据库产生新测量后，会自动恢复真实优先。

## Verification

- 单元测试覆盖三天边界、陈旧记录排除和未来记录排除。
- 集成测试覆盖全部 16 个备件类型、1,781 行测量完整性和近三天时间窗口。
- 浏览器 E2E 验证级联筛选、总数、明细数据、可见测量时间和控制台错误。
