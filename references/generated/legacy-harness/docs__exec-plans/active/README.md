# Active Execution Plans

This folder is for current execution plans that have been accepted and are actively being worked.

## Usage

- Create one short Markdown file per active multi-step task.
- Keep each file scoped to objective, touched files, steps, validation, and rollback.
- Move completed execution plans to `../completed/` or record their durable plan in `docs/plans/index.md`.
