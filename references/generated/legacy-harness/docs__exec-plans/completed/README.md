# Completed Execution Plans

This folder is for completed execution plans kept for historical traceability.

## Usage

- Move completed active execution plans here when their implementation and verification are done.
- Keep completed plans brief; link to durable design docs, specs, or generated outputs rather than duplicating them.
- If a completed plan becomes obsolete, record that in `docs/generated/harness-garbage-collection.md` before deletion.

## Known Completed Plans

- Harness refactor history is currently recorded in `../../plans/plan-harness_refactor.md`.
- PNL indicator improvement history is currently recorded in `../../plans/plan-indicator_improvement.md`.
