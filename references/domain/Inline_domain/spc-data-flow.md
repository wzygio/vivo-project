# SPC 数据链路

本文说明 SPC 报表从用户发起查询到页面展示的主要处理步骤，重点描述数据如何流转和
各阶段产生什么结果，不展开代码、SQL 或算法细节。

## 1. 链路概览

```text
用户查询
  → 固定 SPC 数据范围
  → 获取测量数据与规格
  → 清洗和筛选
  → 应用 Sheet 修饰
  → 生成 Sheet 特征与点位分布数据
  → 筛除能力指标豁免参数
  → 按月/周计算 CPK、CPM
  → 应用能力指标人工修饰
  → 组装报表结果
  → 页面绘图与预警展示
```

## 2. 查询与数据准备

1. 页面根据当前产品和标准报表窗口发起 SPC 数据请求。
2. 应用服务将查询类型固定为 SPC，避免混入 CTQ 或 AOI 参数。
3. 系统获取产品测量数据、参数白名单和规格数据。测量数据优先复用有效快照；需要刷新
   时从数据库补充，数据库不可用时按快照降级规则处理。
4. 共享制备管线依次完成数据清洗、LOSS 参数排除、重复点位去除、参数白名单匹配、
   SPC 类型筛选、异常值过滤、查询范围过滤和主制程信息追溯。
5. 将规格信息合并到测量数据，形成后续分布统计和能力计算使用的统一数据集。

## 3. 异常点过滤工作簿的使用

异常点过滤规则维护在：

```text
resources/inline_domain/spc_outlier_filters.xlsx
```

该文件用于在 Sheet 特征和 CPK/CPM 计算之前，从点位测量数据中物理剔除明显无效的
数值或整个站点的数据。剔除后的点位不会进入分布图、Sheet 汇总或能力指标计算。

虽然文件名以 `spc` 开头，但规则由 Inline 共享制备管线执行；如果相同站点和参数也
进入 CTQ、AOI 或自动预警链路，规则同样可能生效。因此应尽量填写准确的站点、参数，
必要时增加产品范围，避免规则过宽。

### 3.1 列说明

| 列名 | 是否必需 | 设置方法 |
|---|---:|---|
| `prod_col` | 否 | 产品范围。留空、缺少该列或填写 `ALL` 表示全部产品；也可以填写具体产品编码，例如 `M678`。 |
| `step_col` | 是 | 站点编号，例如 `21230`。某行留空时，该行规则会被忽略。 |
| `param_col` | 是 | 参数名。填写时按不区分大小写的完整名称匹配；留空表示无条件剔除该站点下的全部参数。 |
| `lower_col` | 参数级规则至少填一个边界 | 下边界。命中参数且 `param_value <= lower_col` 时剔除。 |
| `upper_col` | 参数级规则至少填一个边界 | 上边界。命中参数且 `param_value >= upper_col` 时剔除。 |

当前工作簿没有 `prod_col` 列，因此现有规则全部作用于所有产品。如果需要按产品隔离，
可以新增名为 `prod_col` 的列，并在对应行填写产品编码。

### 3.2 参数级边界规则

同时填写 `step_col` 和 `param_col`，再填写至少一个数值边界：

| prod_col | step_col | param_col | lower_col | upper_col | 效果 |
|---|---|---|---:|---:|---|
| `ALL` | `21230` | `JNCD_30` | `0` | `100` | 剔除值小于等于 0 或大于等于 100 的点，只保留 `0 < value < 100`。 |
| `M678` | `21240` | `SR_IJP1_T_1_UNI` | `1` | 留空 | 仅对 M678 剔除值小于等于 1 的点，不设置上界。 |
| `ALL` | `21230` | `B_0_CIE_Y` | 留空 | `0.06` | 剔除值大于等于 0.06 的点，不设置下界。 |

注意：上下边界本身也会被剔除。如果希望保留边界值，需要把过滤阈值设置到边界之外。

### 3.3 整站排除规则

填写 `step_col`，将 `param_col` 留空，即表示无条件剔除该站点下的所有参数；此时
`lower_col` 和 `upper_col` 不需要填写。例如：

| prod_col | step_col | param_col | lower_col | upper_col | 效果 |
|---|---|---|---|---|---|
| `M678` | `21230` | 留空 | 留空 | 留空 | 只对 M678 删除 21230 站点的全部测量点。 |

这是影响范围最大的规则。若只需要过滤某个参数，应明确填写 `param_col`，不要使用整站
排除。

### 3.4 匹配和组合规则

- 产品编码不区分大小写，必须完整匹配；`ALL` 或空值代表所有产品。
- 参数名不区分大小写，必须完整匹配，不支持包含匹配、通配符或正则表达式。
- 站点编号按文本匹配；Excel 将编号保存成类似 `21230.0` 时，系统也会兼容对应的
  `21230` 文本值。
- 多行规则采用累加关系：一个点命中任意一条规则就会被剔除，规则顺序不影响结果，
  后面的规则不能恢复已被前面规则剔除的数据。
- 参数级规则的上下边界都留空或填写为非数值时，系统会将工作簿视为无效配置并停止
  本次报表构建，不会静默跳过该规则。

### 3.5 推荐维护流程

1. 使用 Excel 打开原工作簿，保持表头名称不变。
2. 每行只表达一条规则；优先使用精确的产品、站点和参数组合。
3. 保存后关闭 Excel，避免文件锁定影响系统读取。
4. 回到报表页面点击页头的“刷新缓存”，使新规则进入新的数据处理结果。
5. 检查目标参数的点位数量、分布图和 CPK/CPM 是否符合预期，同时抽查其他产品和站点
   是否被误过滤。

文件缺失、无法解密、无法读取或缺少 `step_col` / `param_col` 表头时，系统会停止报表
构建并报告配置错误，避免在过滤规则失效的情况下继续生成看似正常的报表。

## 4. 测量修饰与特征生成

1. 系统读取当前产品的 Sheet OOS 决策。
2. 根据决策处理测量点：需要修饰的点进入规格范围，保留真实值的点不变，标记删除的
   记录从当前结果中排除。
3. 基于处理后的点位生成每个 Sheet 的均值、极值、时间、设备/腔室和规格等特征。
4. 原始点位与 Sheet 特征同时保留，分别服务于点位图、周期分布图和能力指标计算。

## 5. CPK/CPM 能力计算

1. 系统从 `inline_domain.yaml` 读取能力指标参数豁免列表。
2. 参数名包含任一豁免文本时，该参数不进入 CPK/CPM 计算；匹配不区分大小写，按普通
   文本包含关系处理。被豁免参数仍保留在点位和分布图中。
3. 未被豁免的参数按产品、厂别、站点、参数及月/周周期分组。
4. CPK 和 CPM 共用同一条规格准入规则：必须同时具备有效 USL 和 LSL，`LSL` 不能为
   `0`，并且 USL 必须大于 LSL。任一条件不满足时，两项指标都不计算。
5. 月、周周期计算 CPK/CPM；日周期只保留均值和波动信息，不生成能力指标。
6. 波动口径由配置决定，可使用 Sheet 均值之间的波动，或周期内全部有效点位的波动。

## 6. 能力指标修饰与结果组装

1. CPK 和 CPM 分别读取各自的人工修饰记录。
2. 未启用修饰时保留系统计算值；启用且存在有效修正值时，以人工修正值作为最终展示值。
3. 系统将周期能力结果、Sheet 特征、原始点位、指标清单及修饰信息组装成 SPC 报表结果。
4. 稳定的原生数据结果进入缓存；页面展示对象在缓存外构建。缓存标识包含数据版本、
   决策版本、能力计算口径和参数豁免配置，配置或数据变化后不会继续复用旧结果。

## 7. 页面展示

1. 用户通过厂别、站点和参数级联筛选结果，页面展示月/周/日分布、Sheet 点位分布及
   CPK/CPM 汇总。
2. Sheet 点位图根据参数名配置选择折线图或箱线图。
3. 当 `LSL` 为空或为 `0` 时，图中只绘制 USL/UCL，不绘制 LSL/LCL/Target；这一展示
   规则与 CPK/CPM 的单边规格准入规则保持一致。
4. 符合能力指标预警条件的结果进入相应预警展示。

## 8. 关键业务约束

- 参数豁免只影响 CPK/CPM，不删除原始测量、Sheet 特征或分布图数据。
- CPK 与 CPM 使用同一条双边规格准入规则，不能分别判断是否可计算。
- `LSL=0` 是仅上限规格标记，不应作为真实下限参与能力计算。
- 日粒度用于趋势观察，不承载 CPK/CPM。
- 人工修饰作用于已有结果，不改变原始数据库记录或原始快照。
