# SPC 数据链路

本文以 `app/pages/SPC监控报表.py` 和 `src/inline_domain/application/spc/spc_service.py` 为入口，梳理 SPC 从后端取数到前端展示的数据链路。后端按当前代码的 DDD 层级 **infrastructure、core、application** 组织，前端单列 **app** 展示层。各步骤说明处理逻辑、输入输出及相互关系，不展开 SQL 或逐行代码。

核对日期：后端 2026-09-09，前端 2026-09-10。分层按当前实现归属记录：清洗、异常点过滤和主制程追溯目前在 infrastructure；能力豁免和计算截止日选择目前在 application。本文不将它们重新归类为理想架构中的职责。

## 1. 链路概览

以下层名、步骤名与正文标题逐一一致。该列表是分层导航，不表示运行时先完整执行 infrastructure、再完整执行 core；实际由 app 发起查询，application 编排并交替调用另外两层，结果再交回 app 展示。

```text
2. infrastructure：数据访问与持久化层
   2.1 获取三厂测量数据与共享快照
   2.2 清洗无效记录与保留最新点位
   2.3 匹配参数白名单与 SPC 分类
   2.4 应用异常点过滤规则
   2.5 限定测量查询范围

   2.7 获取并覆盖管控规格

   2.9 读取并保存能力修饰台账

3. core：领域规则与计算层
   3.1 校正源测量偏差
   3.2 汇总 Sheet 特征与关联规格
   3.3 识别单片超规与应用 Sheet 修饰

   3.8 匹配并应用能力修饰

4. application：用例编排与结果输出层
   4.1 接收查询并固定 SPC 范围

   4.3 编排 OOC 台账与过货事实更新
   4.4 排除能力豁免参数并确定截止日
   4.5 编排周期能力计算与两项能力修饰
   4.6 组装报表结果并处理缓存与异常

5. app：页面交互与可视化层
   5.1 确定产品、查询窗口与刷新入口

```

实际数据流为：接收 SPC 查询 → 获取并制备测量与规格 → 生成修饰前 Sheet 特征 → 读取决策并修饰点位 → 重算 Sheet 特征 → 排除能力豁免参数并确定截止日 → 汇总周期并计算能力 → 依次应用 CPK、CPM 台账修饰 → 输出报表结果。

源偏差校正在写入测量快照前执行；OOS/OOC 明细和过货事实使用修饰前数据，构成旁路。周期能力使用修饰后数据，能力修饰只改变匹配周期的能力值。

## 2. infrastructure：数据访问与持久化层

本层获取测量、规格和履历，制备可用于分析的数据，并读写快照与人工修饰工作簿。`infrastructure/spc/spc_repository.py` 是 SPC 的薄入口，主要处理由 `infrastructure/shared/` 承担。

### 2.1 获取三厂测量数据与共享快照

系统汇集 ARRAY、OLED、TP 的测量记录，保留产品、厂别、生产载体、站点、参数、点位、测量值、时间和测量单元。ARRAY 使用 Sheet 标识，OLED、TP 的 Glass 标识统一进入后续名为 Sheet 的字段；这一处理不改变实际生产载体的粒度。

产品测量数据优先使用仍有效且满足覆盖要求的共享快照。需要更新时读取数据库，通常重新读取尾部两天的重叠范围并替换旧记录，以接收迟到数据或源记录修订。保留窗口按月滚动，为截止日所在月月初向前 3 个月至截止日。

新读取的数据在写入快照前调用“3.1 校正源测量偏差”；后续清洗、异常过滤和 Sheet 修饰不写回该快照。若启用日期前推，在快照输出时转换为显示时间，快照自身保留源时间。

数据库读取失败时，只能退回可读取、通过校验且满足所需起始覆盖范围的旧快照；不满足条件时报告错误。此降级仅保障测量快照，不代表参数白名单和规格也具有相同降级能力。

### 2.2 清洗无效记录与保留最新点位

先剔除无法识别测量时间或测量值的记录，再排除参数名包含 LOSS 的记录，匹配不区分大小写。

随后按“产品＋厂别＋Sheet＋站点＋参数＋点位”识别重复测量，同一组合只保留测量时间最新的一条。这样重复上传或重复测量不会让同一点位在后续统计中被重复计数。

### 2.3 匹配参数白名单与 SPC 分类

按产品读取参数白名单，将参数名称统一大小写后匹配，并将白名单中的类型归入对应业务分类。SPC 请求只保留白名单中属于 SPC 的参数。

没有匹配到白名单的测量记录被排除；白名单为空时没有可继续处理的测量数据。当前正式数据源读取失败会报错。共享制备另有“未提供白名单则标记 UNKNOWN”的兼容分支，不应把它理解为正常 SPC 白名单缺失时仍可放行。

参数类型归类规则由 core 的参数分类器提供，白名单读取、匹配和 SPC 数据筛选由本层的共享制备管线执行。

### 2.4 应用异常点过滤规则

当前规则文件为 `resources/inline_domain/spc/spc_outlier_filters.xlsx`。它在 Sheet 汇总之前物理剔除命中的测量记录，剔除后的点位不会再进入 Sheet 特征和能力计算。

| 列名 | 处理逻辑 |
|---|---|
| `prod_col` | 可选。缺列、留空或 ALL 表示全部产品；填写产品编码则只作用于该产品，完整匹配且不区分大小写。 |
| `step_col` | 站点编号。某行留空则忽略该行规则；兼容 Excel 将整数站点显示为带 .0 的形式。 |
| `param_col` | 参数名。填写时完整匹配且不区分大小写；留空表示剔除该站点的全部参数。 |
| `lower_col` | 参数级下边界，测量值小于等于该值时剔除。 |
| `upper_col` | 参数级上边界，测量值大于等于该值时剔除。 |

例如下边界为 0、上边界为 100，只保留严格介于 0 和 100 之间的值；边界本身也被剔除。只填写一个边界则只检查该方向。整站排除不需要数值边界。

多行规则累加生效，命中任意一条即剔除，后面的规则不能恢复数据。参数名称不支持包含匹配或通配符；参数级规则至少要有一个可用数值边界。

文件缺失、无法读取或解密、缺少必要表头，以及参数级规则没有有效边界，都会导致配置错误，不会静默放行。维护时保持表头不变，配置修改后需要触发重新计算，才能检查过滤后的点位数量与结果。

该规则由 Inline 共享制备链路执行，因此也可能影响消费同一制备数据的 CTQ、AOI 和自动预警。应按所需产品、站点和参数限定范围。

### 2.5 限定测量查询范围

保留请求开始日零点至结束日全天的测量数据。共享制备管线还支持按厂别、站点、参数进一步限定范围。

当前 SPC 应用服务调用共享特征入口时，以产品、起止日期和 SPC 类型重新构造请求，没有把原查询中的厂别、站点、参数传入这个入口。因此，不能把底层支持的维度筛选误认为 SPC 主服务已经执行了这些筛选。

范围过滤后没有数据时，结束本次测量制备，不继续追溯。

### 2.6 追溯主制程设备与腔室

根据产品、检测站点和参数，从规格中找到对应主制程站点及设备/腔室类型，再匹配同厂别、同 Sheet 的过货履历。

仅使用不晚于测量时间的履历，按履历来源优先级选择，并在相同优先级中取最近的一次。这样测量点可以关联到此前实际加工的主制程设备或腔室，且不会因一片经过多次加工而复制测量点。

无法匹配时，设备路线回退到原测量单元，腔室路线标记为未知；缺少主制程路线时按检测站点和设备路线兜底。追溯信息保留在点位数据中，不是新增的能力计算分组维度。

### 2.7 获取并覆盖管控规格

按产品获取规格上限 USL、下限 LSL、控制上限 UCL、控制下限 LCL，以及主制程路线信息。产品配置存在规格覆盖项时，按产品、站点和参数匹配已有规格，替换指定的上下限或目标值 Target，未指定项保留原值。

覆盖只作用于已存在的匹配规格，不自动创建新指标。产品覆盖配置读取失败时，当前实现记录提示并继续使用原规格，不等同于异常点工作簿的强制失败策略。

输出为供 application 调用、core 关联的产品规格表。规格覆盖与测量制备是两个输出分支；主制程追溯会另外读取规格中的路线信息。

### 2.8 读取并保存 Sheet 异常台账

Sheet OOS 决策工作簿为 `resources/inline_domain/spc/spc_sheet_oos_decoration.xlsx`，当前异常明细按产品分表，独立人工决策表名为“产品编码＋__flags”。本层读取决策，接收上层生成的明细，并保存合并后的结果。

当前明细和人工决策分开维护，重建明细时保留决策。首次生成、产品刷新、决策变更或达到 4 小时明细刷新间隔时允许重写；是否需要更新由共享规则判断，本层负责实际读写。

OOC 工作簿为 `resources/inline_domain/spc/spc_sheet_ooc_decoration.xlsx`，保存修饰前特征生成的 OOC 明细及其独立决策。SPC 主链路不会读取 OOC 决策去修改能力计算点位。

Sheet OOS 决策读取失败会向应用层报告错误，不当作空决策继续。

### 2.9 读取并保存能力修饰台账

能力修饰工作簿为 `resources/inline_domain/spc/spc_cpk_cpm_decoration.xlsx`：CPK 使用产品编码命名的表，CPM 使用“产品编码＋_cpm”。

本层读取已有记录，调用 core 的合并规则，将应用层传来的新增异常追加到对应表，保留已有记录、人工决策和替换值；不因本次计算达标或不在当前窗口就自动删除旧记录。需要生成或补齐的替换值也在此保存，以供后续复用。

能力工作簿读取失败时，当前实现保留原文件并记录异常，返回按本次异常生成的默认未启用修饰记录；因此可继续使用计算值，但无法保证历史能力修饰已应用。写入失败会记录异常，不能将本次内存结果等同于已成功保存的台账。

## 3. core：领域规则与计算层

本层接收数据并执行领域判断，输出校正点位、Sheet 特征、异常明细或周期能力，不负责数据库和工作簿读写。

### 3.1 校正源测量偏差

此规则在共享测量快照写入前由 infrastructure 调用，用于修正已确认的量测偏差：

- M673 中参数名包含 PPA、点位编号为 96～114 的测量值减 5。
- 其余所有 PPA 测量值减 1，两条规则不叠加。
- 其他参数保持不变。

规则只返回校正后的点位；快照保存由 infrastructure 完成。这项校正进入共享快照，后续 SPC、CTQ 等消费者会共同使用。

### 3.2 汇总 Sheet 特征与关联规格

将同“产品＋厂别＋Sheet＋站点＋参数”下的点位汇总为一条 Sheet 特征。计算前再次按点位保留最新记录，然后计算点位均值、最大值、最小值，并取保留点位中最早的测量时间作为该 Sheet 特征时间。

按产品、站点和参数关联规格，输出包含统计值与规格线的 Sheet 特征。同一规则在 Sheet 修饰前后各调用一次：第一次为识别真实超规提供依据，第二次为能力计算提供修饰后的输入。

这里的“修饰前”已完成源校正、清洗和异常点过滤，只是尚未应用 Sheet OOS 决策。

### 3.3 识别单片超规与应用 Sheet 修饰

只要 Sheet 最大值超过 USL，或最小值低于 LSL，就将该 Sheet 指标登记为单片超规；两边均超出则记录双向超规。因此，即使 Sheet 均值仍在规格内，个别点超规也会进入这里的处理。

使用应用层提供的决策，按“产品＋站点＋参数＋Sheet”匹配当前超规明细；本层不读取工作簿。

| 决策 | 处理逻辑 |
|---|---|
| True | 仅将匹配 Sheet 指标中超出规格的点移入规格内，原本合规的点保持不变。 |
| False | 保留该 Sheet 指标当前的实际测量值。 |
| Delete | 删除匹配 Sheet 指标的全部点位，不只是其中超规的点。 |
| 没有决策或空值 | 默认按 True 处理。 |

True 修饰需要同时存在上下规格且 USL 大于 LSL。上侧超规点移至上限以内、下侧超规点移至下限以内，距相应边界约为规格跨度的 5%～15%；同一输入得到稳定结果，不会每次刷新任意变化。缺少有效双边范围时保留原点值，不能保证修饰后合规。

这里的点位修饰条件与能力计算条件分别判断：能力计算额外排除 LSL 为 0 的情况，不能把这项限制直接套用于本步骤。

### 3.4 识别修饰前 Sheet OOC

使用修饰前 Sheet 特征识别控制限异常：Sheet 均值超过 UCL 或低于 LCL，并且该 Sheet 没有点位超出 USL/LSL 时，生成 OOC 明细。

OOS 优先于 OOC，同一条已发生点位超规的 Sheet 指标不会在这里再登记为 OOC。缺少某一方向的控制限时，不产生该方向的 OOC。

本步骤只输出异常明细，保存由应用层交给 infrastructure 完成；它不修改测量值，也不改变后续能力计算口径。

### 3.5 构建月周日周期并汇总统计

接收 application 确定的能力计算截止日，在其上月及当月范围内构建实际有数据的月、ISO 周和日周期。周按周一至周日划分，跨月周可保留输入中已有的周初数据；没有数据的周期不补成零能力值。

按“产品＋厂别＋站点＋参数＋周期”分组，统计 Sheet 数量、均值、波动及规格。不同厂别不会混算；同一指标下不同设备或腔室不会在本步骤另行拆组。

周期均值始终是各 Sheet 均值的平均，每个 Sheet 等权，不按 Sheet 点位数重新加权。波动有两种口径：

| 波动口径 | 处理逻辑 |
|---|---|
| Sheet 均值波动 | 衡量周期内各 Sheet 均值之间的差异。 |
| 全部点位波动 | 衡量周期内所有有效测量点之间的差异，同时记录点位数。 |

当前配置使用全部点位波动。即使选用该口径，周期均值仍保持 Sheet 等权平均。找不到相应点位统计时回退到 Sheet 均值波动；样本不足导致波动无法计算时，不把能力值强行填为零。

汇总前排除 Sheet 均值、USL 或 LSL 缺失的特征。周期规格取组内首个可用值，不按历史规格版本拆分；因此这里描述的是当前规格口径下的周期能力。

月、周进入后续能力计算，日周期仅保留均值、波动和样本信息。

### 3.6 判断规格准入并计算 CPK、CPM

CPK 和 CPM 使用同一准入条件：均值、波动和上下规格不能缺失，波动不能为负，LSL 不能为 0，并且 USL 必须大于 LSL。任一条件不满足时不生成该能力值。

CPK 关注均值离较近规格边界还有多少余量，并结合波动判断能力；均值靠近或越过边界，能力会下降。CPM 同时考虑波动和均值偏离目标的程度；目标未提供时使用上下规格的中点。

仅月、周计算两项能力，日结果留空。零波动属于特殊情况：可能产生无穷能力值；CPK 也可能因均值落在边界上得到 0，或因越界得到负无穷。不能将这些结果理解为普通有限达标值。

### 3.7 筛选上一完整周能力异常

接收应用层提供的参考日期，选取该日期的上一完整 ISO 周中 CPK 或 CPM 低于 1.33 的记录，输出能力修饰台账的新增候选。

本周、月度、达标或缺失能力值不作为新增候选。该筛选只决定哪些记录可以新进入台账，不负责保存，也不限制已有月、周修饰记录的后续应用范围。

### 3.8 匹配并应用能力修饰

按“产品＋厂别＋站点＋参数＋周期类型＋周期标签”匹配能力修饰，CPK 和 CPM 分别应用。

- 未启用修饰、决策留空或无有效启用标记时，保留本次计算值。
- flag=True 时使用对应 replacement 替换值。该值必须为有限数且严格介于 1.33 和 1.40 之间。
- 替换值缺失或越界时，生成 1.331～1.399 的三位小数，交由基础设施层保存后复用。
- corrected 列保留历史记录值，不是当前启用修饰时实际采用的 replacement 列。

新增台账仅针对上一完整周，但已有的月、周记录仍可作用于当前结果中的匹配周期；历史日记录不参与能力修饰。

能力修饰只改变对应周期的能力值及修饰标记，不反向调整点位、Sheet 特征、均值、波动或其他周期。它不会自动保证 CPK 和 CPM 同时达标。

## 4. application：用例编排与结果输出层

本层安排数据获取、领域计算、修饰台账更新和结果输出。以下顺序对应 SPC 报表主用例。

### 4.1 接收查询并固定 SPC 范围

以 `SpcReportService.get_spc_report_data` 为入口，接收产品、开始日期、结束日期，以及数据版本、决策版本和能力口径等信息。查询不合法时报告构建错误。

服务强制使用 SPC 范围，将产品和日期交给共享特征入口。起止日期由调用方提供，本服务不自行把查询开始日改成上月 1 日；能力计算内部的周期窗口另由 core 决定。

SPC 服务通过数据端口获取测量与规格，组合根 `composition.py` 将端口接到 SPC 仓储和共享制备仓储。应用层负责安排步骤，数据库读取与快照处理由 infrastructure 执行。

### 4.2 编排测量获取与 Sheet 修饰前后计算

共享特征入口先请求制备后的测量数据与产品规格，并再次限定起止日期。随后按以下顺序编排 core 与 infrastructure：

1. 调用“3.2 汇总 Sheet 特征与关联规格”，得到修饰前 Sheet 特征。
2. 识别超规，读取并合并 Sheet 决策，更新当前异常明细。
3. 调用“3.3 识别单片超规与应用 Sheet 修饰”，得到修饰或删除后的点位。
4. 再次调用“3.2 汇总 Sheet 特征与关联规格”，生成修饰后 Sheet 特征。

整组点位被删除的 Sheet 指标不再出现在修饰后特征中。主路向后输出修饰后点位与特征，同时保留修饰前特征供异常与过货旁路使用。

### 4.3 编排 OOC 台账与过货事实更新

正式 SPC 仓储声明支持共享事实更新时，应用层调用“3.4 识别修饰前 Sheet OOC”，并将结果交给 infrastructure 保存到 OOC 工作簿。规格整体为空时跳过 OOC 更新，避免将无法判定误当成没有异常。

同一旁路将修饰前 Sheet 特征交给过货事实服务更新，避免 Delete 决策抹掉实际发生的过货。无测量数据时也有空窗口更新分支；这些更新按各自的覆盖范围和持久化规则处理。

此旁路不把 OOC 决策重新应用到 SPC 点位，也不把异常台账当作能力计算的测量输入。

### 4.4 排除能力豁免参数并确定截止日

从配置读取能力计算豁免文本。参数名包含任意豁免文本时，同时从能力计算用的点位和 Sheet 特征中排除；匹配不区分大小写，按普通文本包含关系处理。

当前配置豁免 PPA。PPA 仍保留在输出的点位、Sheet 特征和指标清单中，前面的源校正、异常过滤及 Sheet 修饰仍然适用。若全部参数都被豁免，仍可输出点位与特征，但能力表为空。

在能力计算用的 Sheet 特征中找到最新日期，与查询截止日比较，取较早者作为能力计算截止日。这样没有新增测量时，计算周期不会机械延伸到查询日。

参数豁免与截止日选择目前直接位于 `spc_service.py`，因此按当前实现归入 application，不因它们包含业务判断就写成 core 的职责。

### 4.5 编排周期能力计算与两项能力修饰

应用层读取能力波动口径，调用“3.5 构建月周日周期并汇总统计”和“3.6 判断规格准入并计算 CPK、CPM”。当前配置使用全部点位波动，因此同时传入修饰后点位；选择 Sheet 均值口径时使用 Sheet 特征计算。

得到能力表后，先处理 CPK，再处理 CPM。每次依次调用 core 筛选新增异常、infrastructure 读取并保存对应台账、core 应用能力修饰，最后将修饰后的能力表传给下一步。

新增异常的参考日期固定采用查询截止日，而不是最新 Sheet 日期。例如查询截止日为 9 月 9 日，即使最后测量日更早，也不会将另一个更早的周自动当作上一完整周。

能力计算输入已经经过 Sheet 修饰；服务不再并行计算一份未修饰点位口径的 CPK/CPM。两项能力修饰分别生效，不反向重算 Sheet 数据。

### 4.6 组装报表结果并处理缓存与异常

服务返回以下数据：

| 输出 | 内容与用途 |
|---|---|
| 周期能力表 | 月、周的最终 CPK/CPM，日粒度的趋势统计，以及能力修饰标记。 |
| Sheet 特征 | 修饰后均值、极值、时间和规格。 |
| 点位明细 | 修饰后的测量点，保留测量与主制程追溯信息。 |
| 指标清单 | 从完整修饰后特征中提取的产品、厂别、站点和参数组合，包含能力豁免参数。 |
| 修饰结果 | Sheet OOS、CPK、CPM 的明细、决策或工作簿信息，供后续消费者使用。 |

输出名 `raw_measurements_df` 表示点位粒度，但内容已经清洗和修饰，不能当作数据库原值。

共享特征结果与 SPC 报表结果分别缓存。产品、日期窗口、数据版本、产品刷新标识、Sheet 决策签名影响共享特征复用；能力口径、豁免配置及能力工作簿版本还影响最终报表复用。缓存中保存数据结果，返回对象在缓存外组装。并非任意资源文件修改都会自动触发重新计算。

测量为空、规格整体为空或 Sheet 特征为空时返回空报表；能力输入全部被豁免时只将能力表置空。Sheet OOS 工作簿读取失败报告专门错误，其他未处理构建异常报告报表构建失败；能力工作簿的读取降级按“2.9 读取并保存能力修饰台账”执行。

以上结果进入 app 层。页面以完整产品数据构建自动预警，以已提交的筛选条件构建手动查询结果，两条展示分支消费同一份后端输出。

## 5. app：页面交互与可视化层

本层接收 application 输出的能力表、Sheet 特征、点位明细、指标清单与修饰结果，组织筛选、预警、图表和维护入口。页面脚本负责装配，`app/sections/inline_domain/spc/` 负责 SPC 展示组装，`app/charts/inline_domain/` 与共享 sections 提供绘图和交互能力。图表类型不由后端能力表中的字段决定。

### 5.1 确定产品、查询窗口与刷新入口

页面从当前会话配置取得产品编码，从公共时间窗口取得结束日期，再按 SPC 周期窗口规则推导开始日期，构造只包含产品、日期和 SPC 类型的查询。页面没有单独的日期选择器，手动选择厂别、站点和参数不会改变这次后端查询范围。

页头提供产品切换与刷新入口。产品编码、`spc_sheet_oos` 和 `spc_cpk_trend` 指标的缓存版本共同进入页面签名；该签名还作为产品刷新标识传给后端。刷新处理器调用当前产品的共享原始测量刷新，避免将页面筛选后的数据当作完整产品快照。

同时加载站点描述映射。站点选择器、预警表和指标标题可显示“站点编号＋描述”，筛选和数据匹配仍使用原站点编号，不用显示名称作为业务键。

### 5.2 接收报表结果并处理页面状态

页头渲染后，页面读取 Sheet 决策签名，在加载提示中调用应用服务，并拆出“4.6 组装报表结果并处理缓存与异常”列出的各项输出。

| 返回状态 | 页面处理 |
|---|---|
| Sheet OOS 修饰表读取失败 | 显示工作簿读取错误与重试提示，停止后续展示。 |
| 报表构建失败 | 显示报表加载错误，停止后续展示。 |
| Sheet 特征或指标清单为空 | 显示“当前产品暂无可展示的 SPC 数据”，不继续生成筛选和预警区。 |
| 有特征与指标，但能力表为空 | 继续提供筛选、单片预警及分布图；能力区按可用结果显示空状态。 |

“无可展示数据”是后端输出为空的统一表现，不能仅凭该提示判断数据库完全没有该产品。分类过滤、无有效规格或处理后没有特征等情况，也可能进入同一页面分支。

### 5.3 建立级联筛选与查询门控

筛选候选来自完整指标清单，而不是能力异常表，因此能力豁免参数仍可被查询。选择顺序为厂别、站点、参数名称：厂别限定站点范围，所选站点再限定参数范围；站点和参数支持多选。

切换厂别时清空站点和参数选择。站点组合改变后，自动选择该组合下的全部可用参数；旧选择中已不可用的值会被移除。没有选中站点时，参数选择器不可操作。

只有厂别、站点和参数都已选定时才能点击“查询”。点击后保存当前选择组合；后续选择一旦变化，当前组合与已提交组合不一致，手动结果区提示“当前筛选条件尚未查询”，直到再次点击查询。

这道门控只控制手动结果区。产品级后端加载已经完成，自动预警也会继续生成，不要求先点击查询。

### 5.4 组装全产品能力与单片预警

页面按 CPK、CPM、单片异常的顺序生成预警区，均使用当前产品的完整结果，不受手动查询条件限制。

| 区域 | 输入与筛选 | 输出 |
|---|---|---|
| CPK 预警 | 最终周期能力表；查询结束日期的上一 ISO 周；CPK < 1.33 且未标记已修饰。 | 厂别、站点、参数、周次、CPK 值。 |
| CPM 预警 | 同一能力表；同一上一周；CPM < 1.33 且未标记已修饰。 | 厂别、站点、参数、周次、CPM 值。 |
| 单片异常预警 | Sheet OOS 修饰结果中的异常明细；上一 ISO 周且 flag=False。 | 厂别、站点、参数、Sheet、超规时间、超规类型。 |

CPK 和 CPM 分别判断，不能用其中一项的修饰状态替代另一项。能力区有预警时显示数量与明细；无预警时根据能力表是否为空选择无预警提示或无能力数据提示。日度能力为空不会产生能力预警。

预警明细再按“厂别＋站点＋参数”匹配能力、特征和点位三份数据，自动生成每个异常指标的图表，无需通过筛选器查询。这里仅用指标键筛图，不把整组图表限制在报警周或某个报警 Sheet；图中仍可保留该指标的其他月、周、日及其他 Sheet，供对比。多个异常片命中同一指标时按指标分组出图。

### 5.5 按查询条件筛选并拆分指标

完成自动预警后，页面检查“5.3 建立级联筛选与查询门控”的提交状态。允许展示时，将相同的厂别、站点和参数条件分别应用于周期能力表、Sheet 特征和点位明细，形成三份范围一致的手动查询输入；这一过程不重新计算能力值。

随后以筛选后的 Sheet 特征为主，按“厂别＋站点＋参数”遍历指标，为每个指标截取对应的能力行与点位行。指标标题使用同一组业务键和站点描述。即使某个指标没有能力值，只要仍有 Sheet 特征，就可以展示分布数据。

每个指标输出四项能力摘要、一张月周能力表，以及月周日分布、主制程设备/腔室点位、过货时间点位三张图。自动预警区复用同一套指标组装逻辑，只是输入由异常指标键选出。

### 5.6 生成能力摘要与月周能力表

从指标能力表分别取出有效的 CPK、CPM，生成中位 CPK、最小 CPK、中位 CPM、最小 CPM。摘要使用传入指标范围内全部非空能力行，不先截取能力表最终显示的少数周期，因此摘要不一定等于可见列的中位数或最小值。

能力表只取月度与周度，按周期顺序排序、按周期标签去重，最多保留 2 个月和 3 个周。表格转置为“CPM、CPK 两行，周期为列”，数值保留三位小数，缺失值显示为“-”；不生成日度能力列。

摘要与能力表都消费后端已应用替换值的最终能力结果。flag=True 的匹配周可以显示 1.33～1.40 之间已保存的替换值，但其他月周不会因此被同步替换。下方分布图来自测量点或 Sheet 特征，也不会被能力替换值反向改变。

### 5.7 生成月周日分布图

周期分布图接收指标的 Sheet 特征、能力表及点位明细。优先从能力表的周期结束时间推导显示截止日，没有可用值时使用最新 Sheet 时间；再按现有 Sheet 数据构建最近可用周期轴，最多展示 2 个月、3 个周和 7 个有数据的日。

`period_box_source` 决定分布样本：`point_value` 使用修饰后点位的测量值，`sheet_mean` 使用修饰后的 Sheet 均值。样本按时间分别归入月、周、日，再与显示周期轴匹配；没有样本的周期不绘制箱体。

这张图始终为箱线图，以周期类型区分颜色，横轴为带月、周、日标签的分类轴。日度分布与“不计算日度 CPK/CPM”并不冲突。该样本来源配置仅影响分布展示，不等同于后端决定能力标准差的 `period_sigma_source`。

### 5.8 生成两类 Sheet 点位图

两张 Sheet 图都使用修饰后点位的测量值，不使用能力替换值，也不将主制程分组当作新的 CPK/CPM 计算维度。

前端读取 `line_param_name_contains`，将参数名与配置文本作不区分大小写的普通子串匹配；命中则使用点线图，否则使用箱线图。空配置回退为箱线图，当前 UNI 等参数的展示由配置决定。这一选择同时作用于下列两图，不改变月周日分布图的类型。

| 图表 | 分组与排序 | 展示结果 |
|---|---|---|
| By 主站点设备/腔室 | 使用点位携带的主制程分组信息，按分组、测量时间和 Sheet 排序。 | 箱线模式按 Sheet 展示点位分布、按设备/腔室着色；点线模式按设备/腔室分线，横轴为 Sheet。 |
| By 过货时间 | 按测量时间和 Sheet 排序，生成附带过货时间的 Sheet 标签。 | 箱线模式按 Sheet 成箱；点线模式连接点位值。两种模式均使用 Sheet 分类轴，无过货日期不占据连续时间轴空间。 |

过货时间用于排序、刻度标签和悬浮信息，当前实现不是旧参考文档所述的连续 date 轴。点位图的通用纵轴标签为 Param Value，当前 SPC 绘图入口未按参数追加工程单位。

### 5.9 叠加规格线与确定纵轴范围

三张分布图共用规格线逻辑，从 Sheet 特征中选择首条携带至少一个有效数值规格的记录作为绘线依据，不对每个箱体分别寻找一套规格。

| 规格情况 | 绘线处理 |
|---|---|
| 没有可用规格记录 | 不绘规格线。 |
| LSL 为空或为 0 | 只绘可用的 USL、UCL，不绘下限及 Target。 |
| LSL 为其他数值 | 绘可用的 USL、LSL、UCL、LCL 和 Target；Target 缺失时可取 USL、LSL 中点。 |

当前 CL 线已暂停显示，即使相关推导函数仍保留，也不能将其记为实际展示输出。规格线带名称和数值，纵轴范围结合数据极值与规格范围推导：有效双边规格内的数据可直接使用规格范围，超出时扩展范围并留边距。

这只是绘图策略，不改写后端规格和能力公式。尤其 LSL=0 时，图上不画下限不代表后端忽略这个数值下限。

### 5.10 渲染结果、复用图表与回传人工决策

指标组装先交由 RenderGate 构建图表、能力表与摘要，再统一渲染为每个指标独立的折叠区域。能力摘要和表格位于上方，三张图并排位于下方；图表键包含区域和指标信息，区分预警图与手动查询图。

自动预警图可按签名复用会话中的构建结果，签名涵盖产品/指标缓存版本、预警内容、图表配置和能力结果指纹。能力替换值变化时，即使异常指标集合没有改变，也会重建相关能力展示。当前手动结果区未传入该 memo 签名，不能将两条分支描述为相同的图表复用策略。

管理员 URL 入口额外显示 Sheet OOS、CPK、CPM 三类维护页签。Sheet OOS 下载包含当前明细和独立决策台账，上传只更新决策表；能力页签下载对应产品与指标的能力台账，上传覆盖对应能力 Sheet。保存后的重载重新进入后端修饰链路，而不是直接在图上改数值。能力工作簿的版本参与应用层缓存，后续页面运行可重新读取已保存的 flag 与替换值。

参考分析提供了图表类型、规格线和时间轴的阅读线索；以上以前端当前实现为准，未沿用其旧配置路径、连续时间轴或 CL 显示等已变化的结论。

## 全指标预警矩阵中的 CPK 图像

矩阵 CPK 详情只读 `spc_cpk_cpm_decoration.xlsx` 的产品 CPK sheet，按既有台账状态选择上一 ISO 周预警。
详情自动展示这些厂别、站点、参数对应的历史周 CPK 图像，数值沿用规范化后的 `cpk_corrected`，
红点按台账 `status` 标识，不根据图中数值重新决定人工修饰记录是否预警。
历史限制为截至上周的周记录，不包含本周、未来周、月数据或其他未命中指标。
缺失周不代表达标，图像保留空缺；只有一周记录时只显示一个点。

此入口不调用底层 SPC 测量分析、不回写台账，因此不会提供原始点位分布或控制图。
详情数据随原有台账签名失效，新增图像使用独立图表 key；实现位于
`app/sections/inline_domain/monitor/alert_matrix_detail.py` 与 `app/charts/inline_domain/cpk_ledger_chart.py`。
