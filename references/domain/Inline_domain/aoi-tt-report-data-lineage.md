# AOI_TT 监控报表数据链路（DDD 分层）

## 1. 文档范围

本文说明 `AOI_TT监控报表` 从制造测量事实到报表指标与单片异常预警的业务数据处理链路，并按 DDD 层别划分职责。

本文只描述数据口径、转换规则和层间产物，不解释页面框架、数据库访问方式、缓存、文件读写等技术实现。

## 2. 业务目标与核心口径

AOI_TT 报表用于观察不同产品、厂别和 AOI 站点下的 Total Defect（TT）水平。一个监控指标由以下三项共同确定：

> 厂别 + 站点 + TT 名称

ARRAY 与 TP 的 TT 指标还可按 `Particle Size` 切分为 `Total`、`S`、`M`、`L`、`H`。`Total` 是 SPC 单片总缺陷数；S/M/L/H 默认由站点比例稳定分配，也可切换为缺陷明细中的真实分类计数。OLED 暂时只展示 Total。

报表围绕同一份 TT 单片明细形成四类结果：

1. 月、周、日趋势：观察一个时间段内的平均每片 TT 个数及检测片数。
2. By Lot：观察每个 Lot 内的平均每片 TT 个数。
3. By Sheet：观察每片 Sheet/Glass 的 TT 个数。
4. 单片异常预警：观察上一完整 ISO 周内经人工确认保留真实值的超规格单片。

AOI_TT 属于“越小越好”指标，使用 USL 和 UCL 两条上限作为图像参照。其中，单片是否超规以 `TT 数量 > USL` 判定。

## 3. 总体数据流

```text
三厂 Inline 测量事实 + Particle Size 比例规格/缺陷明细 + 产品映射 + 参数规格
                    │
                    ▼
基础设施层：统一厂别、时间、Sheet/Glass、Lot、站点、参数和值
                    │
                    ├─ 按规格中的“参数类型为空”识别 TT 参数
                    ├─ 按产品、显示日期窗口过滤
                    ├─ 投影为 TT Total 明细与 TT 规格
                    └─ 读取站点 S/M/L/H 比例，或汇总 ARRAY/TP 真实缺陷行数
                    │
                    ▼
应用层：先修饰 Total，再按配置生成或组合 S/M/L/H 明细
                    │
                    ├─ Delete：删除记录
                    ├─ False：保留真实超规值
                    └─ True/未配置：将超规值修饰到 USL 以内
                    │
                    ▼
领域层：按指标 + Particle Size 分别计算趋势、Lot 与 Sheet 结果
                    │
                    ▼
表现层：级联筛选、分组展示三类图像，并展示上一周单片异常
```

## 4. 基础设施层：事实取得与 AOI_TT 投影

### 4.1 输入事实

测量事实来自 ARRAY、OLED、TP 三个厂别。各厂原始载体名称不同，但进入 AOI_TT 链路后统一为同一业务结构：

| 统一字段 | 业务含义 |
|---|---|
| `factory` | 厂别：ARRAY、OLED 或 TP |
| `prod_code` | 产品型号 |
| `start_time` | 该片检测发生时间 |
| `sheet_id` | 检测片标识；OLED、TP 的 Glass ID 也统一进入此字段 |
| `lot_id` | 生产批次 |
| `step_id` | AOI 检测站点 |
| `param_name` | 原始测量参数名 |
| `param_value` | 原始测量值 |

产品型号通过原始产品规格与产品字典的映射确定。只有当前产品的数据进入后续处理。

### 4.2 时间口径

制造事实保留真实发生日期；面向当前客户的报表在数据输出边界将日期统一前推 4 天，形成显示日期。后续报表窗口与月、周、日划分均基于显示日期。

当前页面的显示窗口固定为：

> 上一自然月 1 日至当前日期，首尾日期均包含。

因此，用户看到的某个显示日，对应源系统中提前 4 天发生的制造事实。日期前推关闭时，显示日期与源日期相同。

### 4.3 TT 参数识别

三厂测量事实中混有 SPC、CTQ 等多类参数，不能按参数名称中是否包含 `SUM` 来推断 TT。

AOI_TT 使用产品参数规格作为识别依据：

1. 取得当前产品的参数规格。
2. 选择 `param_type` 为空的规格行。
3. 对 `(step_id, param_name)` 去重，形成当前产品的 TT 参数集合。
4. 仅保留测量事实中站点与参数名同时命中该集合的记录。

该规则使 TT 参数与规格保持同源。某个规格参数若没有实际测量明细，不会单独出现在报表指标中。

### 4.4 TT 明细标准化

命中 TT 参数集合后，字段转换如下：

| 输入 | AOI_TT 产物 | 处理规则 |
|---|---|---|
| `param_name` | `tt_name` | 作为 TT 名称 |
| `param_value` | `tt_qty` | 转为数值；无法解析的值按 0 处理 |
| 三厂各自的 Sheet/Glass ID | `sheet_id` | 统一作为检测片标识 |
| 三厂各自的检测时间 | `start_time` | 转为有效日期时间；无效时间记录剔除 |

页面初次取数只限定产品和固定日期窗口，不提前限定厂别、站点或 TT 名称；这三个维度留给表现层级联筛选。

### 4.5 Particle Size 明细

Particle Size 扩展 ARRAY 与 TP，OLED 暂不区分：

- `Total`：继续使用三厂 SPC `param_value`，不改原口径；
- 默认比例生成：从比例规格表取得各站点 S/M/L/H 基础比例，每片围绕基础比例做稳定扰动，再分别计算并取整四档数量，不做余数补偿；
- 实表模式 ARRAY：以 `ARRAY_DEFECT_T.item119` 区分 S/M/L/H，并保留 `item51='AOI'`；
- 实表模式 TP：以 `TSP_DEFECT_T.item2` 区分 S/M/L/H，以 `cut_id` 关联 SPC `glass_id`，不增加 ARRAY 专属的 `item51` 条件；
- 实表关联前先把 SPC 侧压缩为唯一 Sheet/Glass 到产品映射，避免多条 SPC 参数记录重复放大缺陷行。

比例生成以“厂别 + 产品 + 站点 + Sheet + TT 名称”为稳定业务键；业务键、比例规格和扰动幅度不变时结果不变。缺少站点比例时保持 Total-only。实表模式中某档没有缺陷时补 0。

### 4.6 规格投影

同一批参数规格中 `param_type` 为空的记录同时形成 TT 规格，输出：

- 产品型号；
- 站点；
- TT 名称；
- USL；
- UCL。

规格按 `(step_id, tt_name)` 与指标匹配。规格数据不带厂别，当前业务假设是站点编码已经能够唯一隐含厂别。

### 4.7 与 SPC/CTQ 制备口径的边界

AOI_TT 与 SPC、CTQ 共享三厂原始测量事实，但不复用 SPC/CTQ 的参数白名单分类、LOSS 排除、异常点过滤、主制程追溯或规格覆盖等派生制备规则。

AOI_TT 从共享事实直接按 TT 规格中的“站点 + 参数”组合投影。这保证 AOI_TT 的参数身份、数量和分母不会被 SPC/CTQ 的专属规则改变。

## 5. 应用层：用例编排与超规修饰

### 5.1 报表用例输入

应用层接收当前产品与固定显示日期窗口，依次取得：

1. TT Total 单片明细；
2. 站点 S/M/L/H 比例规格，或 ARRAY/TP 的真实粒径缺陷汇总；
3. 当前产品的 TT 规格；
4. 当前产品的单片超规决策。

如果没有 TT 明细，则报表直接返回空结果，不再生成指标与图像数据。

### 5.2 单片超规清单

应用层在聚合之前，先按 `(step_id, tt_name)` 将 USL 匹配到每条 TT 明细，并筛出：

> `tt_qty > USL`

这些记录形成单片超规清单，保留厂别、产品、站点、TT 名称、Sheet、Lot、检测时间、真实 TT 数量和 USL，供人工决策与预警消费。

没有有效 USL 的指标不参与单片超规判定，但仍可进入普通报表。

### 5.3 三态修饰决策

单片决策键为：

> 产品 + 站点 + TT 名称 + Sheet

每条超规记录按以下优先级处理：

| 决策 | 对报表明细的影响 | 是否进入单片异常预警 |
|---|---|---|
| `Delete` | 从后续报表数据中删除 | 否 |
| `False` | 保留真实超规值，不修饰 | 是，但还需满足上一 ISO 周 |
| `True` | 将超规值修饰到 USL 以内 | 否 |
| 未配置 | 按 `True` 的默认规则处理 | 否 |

默认修饰会把超出 USL 的值稳定地调整到 USL 以下，落在以 0 至 USL 为跨度的 85%～95% 区间。同一条明细重复处理时结果保持一致。

配置为豁免的参数保留真实值，但 `Delete` 的优先级仍然最高。当前豁免按参数名匹配；如果未来 TT 参数命中豁免词，也会遵循该规则。

Total 完成三态修饰后，应用层才生成或组合 S/M/L/H。被 `Delete` 移除的 Total Sheet 不再生成粒径明细；粒径值不再执行 Total 的超规修饰。比例规格或真实 Particle 数据源读取失败时，报表降级为只展示 Total。

### 5.4 报表指标集合

完成删除、释放或修饰后，再从剩余明细中提取唯一的：

> 产品 + 厂别 + 站点 + TT 名称

作为报表可选指标集合。因此，被全部删除且没有剩余明细的指标不会继续出现在筛选项和图像中。

## 6. 领域层：核心指标计算

领域层只消费应用层已经完成修饰的 TT 明细。趋势、By Lot 和 By Sheet 因而使用同一份业务口径，不会一张图使用真实值、另一张图使用修饰值。

### 6.1 月、周、日趋势

趋势以 `厂别 + 站点 + TT 名称 + Particle Size + period` 为分子粒度：

```text
趋势值 = period 内该 TT 的 tt_qty 合计
         ÷
         period 内同厂别、同站点的去重检测片数
```

分母直接来自 TT 测量事实自身，不使用 AOI_RS 过货数据。原因是 TT 为每片必测项，而 RS 站点过货量与 AOI 检测片数不是同一业务口径。

需要特别注意：检测片数按“厂别 + 站点”计算，与具体 TT 名称和 Particle Size 无关。同一站点下多个 TT、Total/S/M/L/H 共用该站点在相同周期的检测片数。分母为 0 时不计算比值。

趋势时间轴组合为：

- 最近 2 个有数据的月度周期；
- 最近 3 个有数据的周度周期；
- 最近 7 个有数据的日度周期。

遇到空周期时向前寻找可用周期补足展示数量。

趋势图同时输出同厂别、同站点、同周期的去重检测片数，作为柱状数据；某周期没有检测记录时记为 0。

### 6.2 By Lot

By Lot 以 `厂别 + 站点 + TT 名称 + Particle Size + Lot` 分组：

```text
Lot 平均每片 TT 个数 = Lot 内 tt_qty 合计
                       ÷
                       Lot 内去重 Sheet/Glass 数
```

各 Lot 按首次检测时间排序。该结果表达的是 Lot 内平均每片水平，而不是 Lot 的 TT 总数。

### 6.3 By Sheet

By Sheet 以 `厂别 + 站点 + TT 名称 + Particle Size + Sheet/Glass` 分组：

```text
单片 TT 个数 = 同一 Sheet/Glass 的 tt_qty 合计
```

各片按首次检测时间排序。正常数据契约下，每个站点、Sheet、TT 只有一条记录，因此该合计通常等于单片原值；若存在多条记录，则会先合计后展示。

### 6.4 规格匹配

三类图像共用同一组 USL/UCL，按 `站点 + TT 名称` 匹配：

- USL：规格上限；
- UCL：管控上限；
- 缺少某条规格时，不绘制对应规格线；
- 规格源预期每个站点与 TT 唯一。若出现重复，图像口径取该组合下较大的 USL/UCL。

## 7. 表现层：筛选、展示与预警消费

### 7.1 手工查询区

表现层从应用层指标集合生成三级联动筛选：

1. 厂别；
2. 站点；
3. TT 名称（页面标签为“Code名称”）。

另提供独立的 Particle Size 多选框。ARRAY/TP 的选项为 `Total/S/M/L/H` 且默认全选，OLED 仅提供 `Total`。每个被选中的粒径均生成月周天、By Lot、By Sheet 三张图；同一站点与 TT 的所有粒径图仍放在同一个 Expander 内。

用户提交查询后，明细与指标集合应用相同筛选条件，再按“厂别 + 站点”分组。每个 TT 展示：

- 月周天平均每片 TT 趋势，并叠加检测片数；
- By Lot 平均每片 TT；
- By Sheet 单片 TT；
- USL/UCL 参照线。

### 7.2 单片异常预警区

预警区只读消费已经形成的单片超规清单，不重新判断超规，也不改变任何修饰决策。

预警筛选条件同时满足：

1. 决策为 `False`，即人工确认保留真实超规值；
2. 超规时间位于上一完整 ISO 周：`[上周一 00:00, 本周一 00:00)`；
3. 时间能够被有效解析。

预警结果按超规时间倒序展示。系统再使用预警记录中的“厂别 + 站点 + TT 名称”精确过滤当前报表数据，并自动生成对应指标的三类图像，无需用户再次手工选择。

如果预警区的只读加载失败，预警区域退化为空，不重新计算预警；如果作为报表修饰依据的决策数据本身无法可靠读取，则停止本次报表重建，避免把“读取失败”误当成“没有人工决策”。

## 8. 分层产物与责任边界

| DDD 层别 | 输入 | 核心业务处理 | 输出 |
|---|---|---|---|
| 基础设施层 | 三厂测量事实、比例规格、ARRAY/TP 缺陷明细、产品映射、参数规格 | 投影 Total；读取并校验站点比例，或按唯一 Sheet→产品映射汇总真实粒径 | Total 单片明细、S/M/L/H 比例或计数、TT 规格 |
| 应用层 | Total 明细、粒径比例/计数、TT 规格、人工决策 | 修饰 Total；按配置稳定生成或组合 S/M/L/H；源失败时保留 Total | 含 Particle Size 的 TT 明细、规格、指标集合、超规决策产物 |
| 领域层 | 含 Particle Size 的 TT 明细、规格 | 分粒径计算 period、Lot、Sheet；检测片数保持站点去重 Sheet 口径 | 分粒径三类图表数据口径 |
| 表现层 | 明细、规格、指标集合、超规决策产物 | 级联筛选与 Particle Size 多选；同一 Expander 分粒径展示三图 | 用户可见报表与预警 |

## 9. 关键业务约束与注意事项

1. **TT 身份由规格驱动**：只认 `param_type` 为空的 `(站点, 参数)`，不依赖参数名称模式。
2. **指标由明细驱动**：有规格但没有测量事实的 TT 不展示。
3. **趋势分母是 AOI 检测片数**：取 TT 测量事实中的去重 Sheet/Glass，不使用 RS 过货量。
4. **所有图像使用修饰后明细**：`Delete`、`False`、`True` 会直接影响趋势、Lot 和 Sheet 结果。
5. **超规判定使用 USL**：UCL 作为图像管控参照，不参与单片超规清单筛选。
6. **只有 `False` 产生单片预警**：默认修饰的超规记录和被删除记录均不报警。
7. **显示日期与源日期可能不同**：当前客户口径统一前推 4 天；周、月、日周期均按显示日期计算。
8. **厂别由明细确定**：规格不含厂别，依赖站点编码在业务上唯一对应厂别。
9. **Total 始终来自 SPC**：Total 与 S/M/L/H 均按 Sheet 取整；比例生成模式对四档独立取整且不分配余数，因此四档合计不要求等于 Total；实表模式同样按缺陷明细独立计数。
10. **SPC 关联必须先去重**：缺陷事实不能直接连接 SPC 多参数明细，否则点位数会按 SPC 行数成倍放大。
11. **Particle Size 厂别范围固定**：ARRAY/TP 区分 S/M/L/H，OLED 保持 Total-only。
12. **生成结果必须稳定**：不得改用运行时普通随机数；稳定业务键或扰动算法变化需要升级缓存身份并记录决策。

### 9.1 现有资料中的口径差异

现有 `spec-data_source-aoi_tt.md` 的图表清单曾把 By Lot 描述为“Lot 的 TT 数量合计”。当前报表实际口径已经是：

> Lot 内 TT 数量合计 ÷ Lot 内去重检测片数

即“Lot 内平均每片 TT 个数”。本文按当前报表处理逻辑记录，后续维护旧数据源说明时应同步修正该描述。

## 10. 口径示例

假设某站点在某周检测了 100 片，其中 `TDSUM` 修饰后的 TT 数量合计为 12,000：

```text
周趋势值 = 12,000 ÷ 100 = 120 TT/片
周检测片数 = 100
```

其中一个 Lot 检测 20 片，修饰后的 TT 数量合计为 2,600：

```text
By Lot 值 = 2,600 ÷ 20 = 130 TT/片
```

某一 Sheet 若只有一条 `TDSUM=150` 的明细：

```text
By Sheet 值 = 150
```

若该 Sheet 的 USL 为 140：

- `flag=False`：报表保留 150，并在满足上一 ISO 周条件时进入单片异常预警；
- `flag=True` 或未配置：150 被稳定修饰到 119～133 之间后参与全部图像计算；
- `flag=Delete`：该条记录不参与任何图像计算，也不进入预警。

本文口径以当前实现及以下已接受的领域决策为准：

- ADR-0008：TT 参数识别、趋势分母与规格口径；
- ADR-0012：Inline 共享测量事实与 AOI_TT 独立投影边界；
- ADR-0014：AOI_TT 单片超规三态修饰；
- ADR-0017：单片异常预警口径；
- ADR-0022：制造事实源时间与显示时间边界。
