# 全产品年度／季度／月度不良率历史

“超规预警看板 → 全产品良率看板”位于 AOI_RS 监控看板之后，使用产品选项卡，独立查询和局部重跑。按当前自然年提供 H1/H2、Q1—Q4、月份多选，默认选中截至当前的周期。时间列按半年、季度、月份排序；行按总不良、Group、Code排序。产品和各项筛选默认全选，取消全部选择表示无选择；增加产品后需点击查询。下载每个产品独立 Sheet。

Code 默认用“全部 Defect Code”单个选项表示全选，避免数百个标签撑高筛选栏；选择具体 Code 自动切换为明细子集，选择“全部”则恢复全范围。

## 月度事实与分母

- 入口仍为 `MWDTrendProcessor`，新增 `create_period_monthly_rates` 处理历史月率，不运行日度随机分配。`core/mwd_trend/period_trend.py` 只计算，不读文件或数据库。
- 分母是当前启用产品及其工单范围内、`last_flag=Y` 的独立入库 Panel 数，按 `first_ship_date` 分月。Defect 表不参与分母查询；Group/Code 筛选均不改变分母。
- 沿用全局日期前推和今日中午截止。历史业务日保留全天；今日业务日要求有效的实际入库时间不晚于截止，比较保留六位小数秒。源日期按显示日期反推；不改写原有滚动 Panel 快照。
- 维护分界在 `config/domain/yield_domain.yaml:period_trend.maintained_rate_start`，当前为 2026-06。此前按单月、产品、工单读取目标 Group 下各缺陷名称的去重 Panel 数，套用配置倍率后向下取整，再除以独立物理分母；Group 为 Code 月率之和。源聚合不拉全量 Panel 明细，也不改变其他报表的修饰算法。
- 自分界月起，**不查询 Defect 事实**，只读取全局资源注册表指向的“入库良率修饰表”。Code 沿用“当月指定 → 最近更早指定 → 当月参考”解析；无可用值记缺失。Group 使用当月指定，空白则使用该行当月参考值，绝不由 Code 重算，也不沿用历史 Group 指定。这是年度历史板的直接维护月率口径；原有 MWD 日／周算法不变。
- 同名缺陷的历史 Code 别名以 ` / ` 连接，只保留一份月率，避免重复统计。维护表中无数据库映射且解析目标全部为零的名称不进入 Code 清单并记录告警；非零孤立名称使查询失败，禁止猜测实际 Code。
- 零过货月不良率为零；正过货缺月／缺值保持 NaN，不能伪装成零不良。季度和半年为 `Σ(月率×月过货)/Σ(月过货)`，其中任何正投入月缺值会使对应汇总缺失。

## 筛选与公开展示

总不良为所选 Group 月率／周期率之和，堆叠图亦使用所选 Group。**Code 仅筛选明细行**，不影响 Group、总不良或过货数。图表、表格和 Excel 导出采用公开字段白名单；不输出维护原值、签名、配置路径、内部标记和原始 Panel。导出禁用公式及 URL 自动识别。

图表的半年、季度、月份保留此顺序，在不同粒度之间增加留白和竖向分隔线，并在横轴下方标注“年度（半年）／季度／月度”。过货折线在粒度边界断开，悬停仍显示真实周期和数值，避免将不同统计口径误读为连续时间推移。

## 历史仓储与更新

组合根 `build_period_trend_service` 注入应用层的 Source/Store 协议。基础设施以单月参数绑定、语句超时和有限聚合结果取数；第一次读取先检查低成本元数据并 EXPLAIN，禁止将无界 COUNT 当规模探查。

`config/global.yaml` 的 `resources.yield_domain.files.period_trend_history` 默认指向 `resources/yield_domain/mwd_trend/yield_period_history.xlsx`，支持配置完整的仓库相对路径或绝对路径。组合根统一解析该配置，读写均使用同一位置；同名 `.xlsx.bak` 备份随主工作簿存放。每产品一个长表 Sheet 保存月率；“投入数”共享 Sheet 按产品／周期类型／周期唯一保存月、季、半年投入；`__meta__` 保存策略、维护版本、当前开放月、刷新时间和发布版本。

- 已关闭月直接复用；当月按全局缓存 TTL 刷新，至少每日失效。跨月时对旧开放月补齐一次，然后关闭；当前季度／半年仅基于月度历史加权，不重拉完整季度。
- 维护表 mtime 变化只重新读取维护月率，不回查历史 Defect／投入。表内容与签名绑定；计算期间变化则拒绝提交，下一次查询重试。
- 产品／工单／日期策略变更拒绝混用旧快照，需显式迁移。全年已关闭月不自动反查迟到历史数据。
- 同一工作簿一次提交月率、全部投入和元数据；OS 发布锁覆盖重读、合并与提交。产品版本 CAS 拒绝同产品过期并发提交；不同产品合并保留。同目录临时文件、验证、备份、原子替换，失败不推进快照。读取兼容企业 Excel 保护；进程内缓存按路径与 mtime 失效。

## 本次季报 Top5

按2026-10-22用户修订要求，一次性分析使用 **6—10月** Code 月率的五个月算术平均排名，只选择均值大于零的 Code，不增加页面 Top5 功能。以当前L1快照为输入，不触发数据库读取、快照刷新或Group月率重建。无过货月按零月率纳入五个月平均；正过货月份的缺率不补零，缺少完整排名窗口的候选予以排除并留存核对明细。各产品取均值最高的五个Code，均值相同时按Code排序；Top5多折线同样展示6—10月。

PPT 的 Top5 表格和折线图例使用 `defect_desc` 中文名称，首列标题为“不良名称”；排名和数据关联仍使用实际 `defect_code`，不会因中文同名而合并不同缺陷系列。名称对应 `data_loader.py` 中 `imp_ct_dft_group.defect_desc` 的数据契约。

按2026-10-23用户修订要求，季报 Top5 折线图对无过货月份留空，不绘制该月点位及与其相连的线段，月份刻度仍保留；有过货且不良率为零的点位正常绘制。此项仅改变季报绘图，不改写L1快照，也不改变上述五个月均值排名规则。
