# Cpk 与 Cpm 计算方法

## 1. 各指标如何计算

以下统计均针对同一指标、同一统计周期内的有效样本。

| 指标 | 含义与计算方式 |
|---|---|
| USL | 规格上限，是预先设定的要求，不由样本计算。 |
| LSL | 规格下限，是预先设定的要求，不由样本计算。 |
| 单片均值 x̄ᵢ | 第 i 个 Sheet 所有有效点位值的算术平均。 |
| μ | 各 Sheet 均值的等权平均，每个 Sheet 权重相同。 |
| σ | 全部有效点位值的样本标准差，分母为点位数减一。 |
| 规格宽度 W | `USL − LSL`。 |
| 规格中点 M | `(USL + LSL) / 2`。 |
| 半规格宽度 h | `(USL − LSL) / 2`。 |
| Cp | `W / (6σ)`，衡量规格宽度相对于测量波动的大小。 |
| Ca | `(μ − M) / h`，衡量均值相对规格中点的偏移比例；计算 Cpm 时取其绝对值。 |

### μ：Sheet 均值的等权平均

设第 i 个 Sheet 有 nᵢ 个有效点位，点位值为 xᵢⱼ；共有 m 个有效 Sheet：

$$
\bar{x}_i=\frac{1}{n_i}\sum_{j=1}^{n_i}x_{ij},
\qquad
\mu=\frac{1}{m}\sum_{i=1}^{m}\bar{x}_i
$$

μ 不按各 Sheet 的点位数量加权。例如两片的均值分别为 9 和 14，μ 就是 `(9+14)/2=11.5`，无论两片各自有多少点。

### σ：全部点位的样本标准差

设全部有效点位共有 N 个，值为 x₁、x₂、…、xN：

$$
\bar{x}_{\mathrm{points}}=\frac{1}{N}\sum_{k=1}^{N}x_k,
\qquad
\sigma=\sqrt{\frac{\sum_{k=1}^{N}(x_k-\bar{x}_{\mathrm{points}})^2}{N-1}}
$$

σ 以**全部点位的均值**为中心计算，分母是 **N−1**。各 Sheet 点数不同时，点位均值可能与 μ 不同。当前口径将全部点位合并计算标准差，不是计算各 Sheet 均值的标准差，也不是平均各 Sheet 的标准差。

## 2. Cpk 的计算方式

$$
C_{pk}=\min\left(\frac{USL-\mu}{3\sigma},\frac{\mu-LSL}{3\sigma}\right)
$$

分别计算均值到规格上限和下限的距离，除以三倍标准差，再取较小值。它反映均值到最近规格边界的余量：均值在规格内时为正，在边界上时为零，超出规格时为负。

也可等价写成：

$$
C_{pk}=C_p(1-|Ca|)
$$

## 3. Cpm 的计算方式

$$
C_{pm}=\frac{C_p}{1+|Ca|}
=\frac{USL-LSL}{6\sigma\left(1+\frac{|\mu-M|}{h}\right)}
$$

先计算 Cp，再按均值偏离规格中点的程度折减。均值等于规格中点时，Cpm=Cp；偏离越大，折减越多。偏移比例按小数代入，例如 25% 使用 `0.25`。

当前 Cpm 以规格中点 M 为基准，不使用工程目标值。对于有效双边规格和正标准差，即使均值已超出规格，Cpm 仍为正数。

以上常规公式以有限数值、有效双边规格及 σ>0 为前提；当前项目还要求 LSL≠0。缺失值、零标准差及备用标准差口径的完整处理见 [SPC 能力计算规则](rules-spc-cpk&cpm.md)。
