# CPK / CPM 汇总工作簿更新规则

核验日期：2026-10-09。范围为 `app/pages/超规预警看板.py` 下方的 CPK / CPM 汇总表和最新项目明细，不改变独立全指标矩阵或 SPC 主报表；原异常片区域标题为“异常片预警看板”。

CPM 复用以下周期、统计、补零和日期排除规则，预警阈值同为 1.33。读取同一 `spc_cpk_cpm_decoration` 工作簿的 `<产品>_cpm` sheet，值字段为 `cpm_corrected`，规范化后的数值字段为 `cpm`。
汇总保存到同一 `monitor_summary_workbook` 工作簿的 `<产品> CPM` sheet（兼容旧版统一 `CPM` sheet），总项目数和达标率列分别为 `CPM总项目数`、`Cpm≥1.33达标率`。CPK 与 CPM 的 sheet、列及查询状态分别管理，避免相互读取或覆盖；CPM 初始化同样不从异常台账推断总项目数。

## 输入与统计范围

- 汇总基线读取全局资源配置 `monitor_summary_workbook`。优先读取 `<产品> CPK` sheet，没有产品 sheet 时兼容旧版统一 `CPK` sheet；旧版缺失的监控类型、厂别分别规范化为 `SPC`、`ALL`。
- 最新项目读取全局资源配置 `spc_cpk_cpm_decoration` 中产品同名的 CPK sheet，不使用 `<产品>_cpm` sheet，也不重新查询原始量测。
- 汇总表及其趋势按所选产品、全部厂别（`ALL`）统计。厂别筛选仅影响最新项目明细，改变或清空厂别选择不会隐藏已查询的汇总；改变产品仍需重新查询。

## 补零与最新周更新

- 在共享工作簿锁内，为所选产品补齐展示日历范围内缺失的基线：当年、截至当前季度的各季度、最近三个月、包含当前周的最近四个 ISO 周。
- 缺失基线的 `CPK总项目数`、`达标项目数`、`预警项目数`、`Cpk≥1.33达标率` 全部置零。不存在工作簿或 CPK sheet 时也支持初始化；已有格式错误或读取失败仍报错，不能当作空基线覆盖。
- 从明细更新的周期仅为上一完整 ISO 周，例如 2026-10-09 更新 `2026-W40`。已有年、季、月及其他周记录保持不变。
- 最新周已有有效正整数总项目数时，沿用既有规则：按业务键去重后，`flag=False` 且 `cpk_corrected < 1.33` 的项目计为预警；达标项目数为总项目数减预警项目数，达标率为达标项目数除总项目数。
- 异常台账不提供完整项目分母。新补零基线不会从异常行数推断总项目数；分母为零或无效、缺明细、存在无法判定项目时保留基线。预警项目数超过有效分母仍报错。

## 日期排除

- 沿用 Inline 厂别及日期排除规则判断最新完整周的 `ALL` 汇总是否跨越排除区间。
- 命中时仅将该最新完整周的四个数值字段持久化为零。已有年、季、月和其他周记录不重置，汇总展示也不因这些周期跨越排除区间而删除它们。
- 明细仍按自己的厂别和周期应用日期排除，再应用界面厂别筛选。因此 ARRAY 明细可能保留，同时该周 `ALL` 汇总为零。
- 完整零基线的达标率显示为 `0.00%`；未知维护值不因补零操作而自动转为已知值。

## 持久化与验证

`CpkSummaryWorkbookStore.refresh_latest()` 在既有跨进程共享锁内读取、规划、合并和写回。写入按产品 CPK sheet 组织，保留报警率及其他工作簿对象，重复查询且值未变化时不重写。

回归覆盖缺失周期/sheet 初始化、最新周计数、年季月及历史周保留、日期排除零值写回、厂别筛选独立、ISO 跨年、格式失败、其他 sheet 保留及重复执行不重写。
