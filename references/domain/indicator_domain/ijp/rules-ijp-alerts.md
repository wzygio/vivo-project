# IJP CODE 注释与上一周自动预警

2026-10-26 用户确认：孔区增加 C3RA0，AA 区和孔区的 CODE 注释使用域配置；仿照 SPC 的上一自然周预警，自动展示超规清单及对应图像，并将超规结果保存为本地 Excel 快照。

## 配置与规格

- `config/domain/indicator_domain.yaml` 的 `ijp.code_descriptions`、`ijp_hole.code_descriptions` 分别拥有 AA 区、孔区注释。筛选项、图例、hover、预警清单使用同一配置；缺少注释的 CODE 仅显示代码，查询值始终保持原始 CODE。
- 孔区的四类代码为 C3RA0、C3RA1、C3RA2、C3RA3；其默认注释在配置中维护，统计规则由 [孔区月周规则](../ijp_hole/rules-hole-period-report.md) 拥有。
- AA 区 C3DM1 占比严格小于 90%，或孔区 C3RA1 占比严格小于 90%，触发预警。恰好 90% 不触发；无数据周期不触发。
- 以服务器当天为参考，取上一 ISO 周的周一到周日，按产品、线体和 Printer 独立判断。月汇总、当前周、前两周不参与此次预警。
- 判定复用当前报表投影的占比。现有 AA 区和孔区的占比修饰继续生效，因而默认配置下目标 CODE 通常不会低于预警规格；预警不额外查询或公开另一套占比。

## 执行与展示

- 页面选定监控区域后自动检查该区域全部启用产品、配置的工单类型，不依赖“查询”按钮，也不受手动产品、线体、CODE、批次筛选影响。
- Application 服务通过现有有界取数端口计算月周结果，由 Core 纯函数选取上一周超规项，并通过应用拥有的 `IjpAlertStore` 端口发布快照；Infrastructure 实现 Excel 写入，composition 绑定配置路径。
- 预警中心有异常时自动展开，显示清单；“自动预警指标图像”只按异常的产品/线体/Printer 精确匹配，展示这些设备的月周报表。无异常、无数据和更新失败使用独立状态文案。
- 公开表格、session、图表和缓存仅传递当前占比及业务字段，不传递原始占比、计数、内部标记或修饰规则。
- 自动预警原生数据缓存 TTL 为 15 分钟，最多 32 项。签名包含区域、窗口、产品及工单配置、域配置、日期前推、截止策略和快照路径。页头“刷新缓存”会清除该缓存并重新计算、发布快照。失败不会缓存为正常结果。

## Excel 快照

- 路径唯一配置来源是 `config/global.yaml` 的 `resources.indicator_domain.files.ijp_alerts`，默认 `resources/indicator_domain/ijp/ijp_alerts.xlsx`。
- `AA区`、`孔区` 两个 sheet 保存各区域最近一次成功计算的上一周超规结果；`__meta__` 保存区域、参考日期、周期起止、更新时间、异常条数和成功状态。首次页面计算时自动创建工作簿，不需要预置或虚构业务记录。
- 保存字段为区域、产品、线体、Printer、CODE、周期起止、占比和规格下限。占比用 0–1 数值存储，页面按百分比展示。
- 每次成功计算替换当前区域 sheet，保留另一区域及其他 sheet。成功的空结果会清除该区域旧预警。取数或计算失败不发布结果；写入失败保留原文件，页面显示更新失败。
- 使用 OS 文件锁串行化读改写；在内存生成并核验 Excel 后，使用同目录临时文件及原子替换发布，失败会清理本次临时文件。此文件是最新结果快照，不是追加型历史台账，也不在取数失败时作为当前正常结果回退。

## 验证

- Core：上一周、跨年、严格阈值、无数据排除及当前报表口径。
- Application：启用产品/工单范围、公开投影、成功发布、计算失败不发布。
- SQLite：C3RA0 缺失补零及真实 SQL 接收 C3RA0；保留时间前推、截止、排除和大孔筛选契约。
- Excel：区域隔离、空结果清除、原子替换失败保留原文件及临时文件清理。
- Streamlit AppTest：无需点击查询即可预警，异常设备精确出图，配置注释、正常/空/失败分支及普通模式字段边界。
