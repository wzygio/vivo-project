# 蒸镀腔室 Q-Time 数据库规则

## 来源和范围

生产组合根使用 `DatabaseChamberQTimeRepository`。腔室事件与LL1来自
`mdw.dwt_inout_sub_unit_gls`，LL1 IN的`prod_id`精确关联
`mdw.dwr_mes_productspec.productspecname`得到`productcode`，不依赖SPC抽样覆盖。
仅OLED、P/E和3CEE01/3CEE02；显示名称仍为3CEE001/3CEE002。
严格限制已启用型号，规格名多版本同型号去重，未知/多型号glass隔离；不猜测产品。
旧Excel适配器保留供显式注入和历史测试，不是生产默认或失败回退。

## 区间口径

按设备、glass和LL1进片时间划分过货批次，事件按完整event_timekey顺序配对。
相关腔室中OUT行与下一事件的时间差为秒，下一UNIT_ID须非空；不是同腔IN/OUT加工时间。
精确重复事件去重，复过货及同次过货内重复转移保留。仅存在真实配对时生成区间；
缺少下一腔不填零。非法/负数测量按缺失；不改写源事实。
11条路径为Core `CHAMBERS`（PT→OC1至OC9→OC10），不包含LL1→UL1和末尾两条扩展路径。

## 日期、安全和缓存

日期按进片显示时间选择，首尾日包含；默认当月、最多31日且不晚于服务器当天。
反算源窗口后按date_timekey前后各补1日扫描，供跨午夜补齐；跨出补齐窗口的长流程不保证
完整，不推造缺失配对。输出应用前推、当天全局截止和Indicator日期排除，然后进入Core。
只读查询、60秒语句超时、500,000条结果上限；超上限拒绝整个结果，不静默截断。
参数化查询；技术原因只写服务端日志，页面使用安全业务错误，不回退旧Excel。

日期变化清理已提交结果、重新查询。缓存以日期、来源、启用范围、前推/截止/排除策略和
规格区分；产品/线体/腔室多选在已查询的日期窗口内即时过滤，空选取全部启用范围。
配置规格控制超限线及纵轴，严格大于才超限；展示继续排除大于1000秒的点。
保留SVG点位和独立fragment，页头刷新同时清理两个模块。
